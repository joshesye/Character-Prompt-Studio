# 02 · 风格图谱

用户说"要个好看的风格"时，**不要反问他"你想什么风格"** —— 那是把活推回去。
从下面 11 个族里挑 2-3 个，每个用一句话说清"出来会是什么样"（说画面，不说术语），让他挑。

族名只是索引，真正的词在 `07-term-library.md`（用 `scripts/lookup.py --section 风格` 查）。

---

## 怎么给候选（比族表本身更重要）

❌ 错：`你想要什么风格？有写实、插画、3D、国风、赛博朋克……`
✅ 对：

> 这张我给你三个方向，你挑一个：
> **① 电影感实拍** —— 像电影剧照，人物有立体感，背景压暗只有环境色，适合讲情绪
> **② 平涂插画** —— 色块干净边界清楚，像杂志插图或绘本，适合配文字
> **③ 国风水墨** —— 留白多、墨色由深到浅，配一点朱红或石绿，适合东方题材
>
> 或者你说个参照（哪部片子 / 哪个画师 / 哪种材质），我照那个方向来。

三条给候选的纪律：
1. **三个候选要跨族**，不要给"赛博朋克 / 蒸汽朋克 / 废土"这种同一族里的三个 —— 那不叫选择
2. **每个候选描述"出来是什么样"，不描述术语**。用户不懂"luminism"，但懂"光像从画里透出来"
3. **必须留一句"或者你说参照"** —— 大多数时候用户其实有参照，只是不知道怎么用术语说

---

## 拿不准就用这三个

默认安全牌，绝大多数题材都能用，不容易崩：

| 族 | 一句话形态 | 为什么安全 |
|---|---|---|
| **电影感实拍** | 照片质感、**一个明确的主光源**、明暗有层次 | 有明确光源就不容易平；模型对摄影先验最足。⚠️ 不要默认"环境压暗" |
| **平涂插画** | 色块清楚、边界干净、有限配色 | 不追求细节，容错率最高 |
| **胶片 / 录像带质感** | 轻微颗粒、泛朦高光、低对比 | 质感本身掩盖 AI 感，出片率实测最高 |

## ⭐ 世界知识锚点 —— 一句话顶五十字

**这是选风格的第二条路径，比"报风格名"更高级。**
模型脑子里存着大量关于时代、地域、作品、创作者的视觉知识。
**给它一个锚点，它会自动补齐一整套符合那个世界的细节** —— 你一个字都不用写。

⛔ 这是治「提示词太长」最有效的办法。不要挨个描述细节，**给个锚点让它自己填**。

### 三类锚点

**① 时代 / 地点锚点（Era anchor）** —— 一个时间地点，唤起一整个视觉世界

| 锚点 | 模型会自动补出 |
|---|---|
| `1969 年 8 月，纽约州伯特利` | 伍德斯托克：扎染、泥地、帐篷、人山人海 —— 不用你写 |
| `1989 年 11 月，柏林` | 墙、涂鸦、人群、亢奋的空气 |
| `1982 年，东京` | 新宿霓虹、模拟电子设备、早期赛博朋克 |
| `1957 年，哈瓦那` | 老式美国车、斑驳的墙皮、铁艺阳台、热带感 |

**② 文化 / 风格嫁接锚点（Cultural anchor）** —— 把一个文化对象的视觉语言挪到另一个语境

| 锚点 | 效果 |
|---|---|
| `用《GTA》的视角拍上海街头` / `Persona 风格的高中教学楼` | 自动套用那个游戏的视觉语言 |
| `苏联构成主义海报，主题是现代 AI` | 罗琴科式的红黑斜构图 + 粗体字 |
| `浮世绘版画，画的是便利店` | 日本木刻版画语言画现代场景 |
| `水墨画，画的是赛博都市` | 东方笔法 + 未来题材 |

**③ 创作者 / 作品锚点（Genre anchor）** —— 拿一个人或一部片当透镜

| 锚点 | 效果 |
|---|---|
| `Peter Lindbergh 的感觉` | 强烈黑白、几乎不修皮、raw 编辑感 |
| `Wes Anderson 的配色` | 对称构图、粉彩色盘、正中构图 |
| `Roger Deakins 的打光` | 自然光、深阴影、电影级的体积感 |
| `吉卜力的氛围` | 柔和水彩天空、绿色植被、暖调怀旧光 |
| `Deakins 的光 + 冷蓝调` | 组合用也行：一个人 + 一个色彩限定 |

⭐ **本项目的词汇库里有一批现成的参照词**：
`scripts/lookup.py --group 艺术家`（米开朗基罗 / 莫奈 / 梵高 / 新海诚 / 宫崎骏 / 皮克斯…）、
`--group 动漫/动画/游戏风格`、`--group 艺术风格`。

### 三条使用规则

1. **只当高层引导，不能代替整个提示词。**
   锚点定"世界是什么样"，**具体细节还得你自己写**。两个都要有。
2. **必须配具体物象。** `吉卜力的氛围` 单写会飘；
   `吉卜力的氛围，一棵长满青苔的树，晨雾里有个僧人在扫落叶` 就落地了。
3. **⛔ 不要叠加多个创作者锚点。** `Lindbergh + Wes Anderson` = 一锅粥。
   **一张图一个锚点**（和"一张图一个成立点"是同一条纪律）。
   要叠加只允许"一个创作者 + 一个色彩/光线限定"这种**主从搭配**。

### 什么时候用锚点，什么时候不用

| 用锚点 ✅ | 不用锚点 ⛔ |
|---|---|
| 用户报了参照（"像宫崎骏那样"、"要王家卫的感觉"）| 用户给了具体到每个元素的描述（这时候锚点会打架）|
| 想要某种"调性"但说不清细节 | 需要精确控制画面结构（商业稿、产品图）|
| 想让画面显得有出处、不 stock | 用户明确要"不要任何人的风格" |

⭐ **给用户候选时可以用锚点来快速试探**，但**要用画面语言解释它**：

> **③ 王家卫的感觉** —— 潮湿的夜、浓艳的招牌色、人物在画面边缘、
> 玻璃和水面反着光，情绪大于情节
>
> （用户不需要知道王家卫是谁，他只要知道"出来会是什么样"）

## 族 1 · 摄影写实

**适用**：人物写真、产品、美食、纪实、生活方式、旅拍
**起手句**：`一张真实照片，[焦段/相机] 拍摄，[光位]打光，浅景深`

| 子方向 | 关键补充 | 备注 |
|---|---|---|
| 商业棚拍 | 干净背景 + 柔光箱 + 无明显阴影 | 产品、美妆 |
| 自然光人像 | 窗光 / 树荫漏光 / 黄金时段 | 最稳的一档 |
| 胶片 | `35mm film` + 自然颗粒 + 轻微色偏 | ⚠️ 吃场景，配硬光会发脏 |
| 录像带 / VHS | 泛白高光 + 轻微朦胧 + 不过分锐化 | 出片率很高 |
| CCD / 数码卡片机 | 近距离 + 硬闪 + 轻微过曝 | ⚠️ **只在"这场景现实里真会有人开闪光灯"时用** |
| 直闪快照 | 背景快速衰减变暗 + 皮肤局部过曝 | 夜街、室内派对 |

⛔ **一张图只能有一个成像系统。** 把 CCD、VHS、35mm film、棚拍、手机自拍同时塞进去，
模型不知道该模拟哪种照片 —— 症状是"每样东西都对但整张就是浑"。
⭐ **成像系统那一句写在最前面当定调句**，塞在句尾会被前面的场景描述盖过去。

## 族 2 · 电影感 / 叙事

**适用**：情绪人像、场景叙事、短剧截图、氛围图
**起手句**：`电影剧照，[画幅]，一个明确的单一主光源` ⚠️ **默认导演不用带"环境压暗"**

- 必配：一个明确的**光源实体入画**（太阳盘 / 一排灯 / 一扇窗 / 一堆篝火）
- 必配：**两个色温**（暖主光 + 冷环境，或反过来）
- ⚠️ **"一块真正的黑"是可选加强项，不是必配** —— 它会把画面整体压暗（见 `03` 构图 ④）。
  只有用户明确要"暗调 / 重 / 戏剧性"时才加
- ⛔ "电影感"三个字本身零效果 —— 要拆成可观察的：白平衡、曝光、反差、高光、锐度、噪点、景深
- ⛔ **"电影感" ≠ "暗"** —— 很多电影感画面是明亮通透的（日戏、雪景、海边）。
  **不要一写"电影感"就压暗**

## 族 3 · 插画 / 绘本

**适用**：儿童绘本、杂志插图、自媒体配图、科普图
**起手句**：`平涂插画风格，色块边界清晰，有限配色`

| 子方向 | 关键补充 |
|---|---|
| 扁平矢量 | 无渐变、无纹理、纯色块 |
| 水彩绘本 | 边缘有水痕、纸纹可见、颜色轻微溢出边界 |
| 线描 + 淡彩 | 线条先定形，颜色是半透明的 |
| 杂志编辑插图 | 概念化、有一个明确的视觉隐喻 |
| 儿童插画 | 比例夸张、圆润、暖色为主 |

⭐ 插画族的**画幅自由度高**，不像特写被画幅卡死；配文字时优先 4:3 / 16:9。

## 族 4 · 动画 / 二次元

**适用**：动漫人物、游戏立绘、Q 版、番剧感场景
**起手句**：`日式动画风格，[线条类型]线条，[配色]`

- 必须明确**线条风格**（`07` 的 风格/线条 有 58 条）：轮廓线画 / 交叉线描 / 单线画 / 负空间画
- 场景类参考：吉卜力（自然、暖）、新海诚（天空、光斑、细腻）、京都动画（日常、柔和）
- ⛔ 二次元人像最容易崩的是**手**和**眼睛对称** ——
  ⛔ **但不要靠收尾句写"双手五指完整"来防**（那是反效果的，见 `04` 的「收尾句不要写身体部位的质量要求」）。
  两条正解：**① 手的质量靠"手在做什么"来定** —— 写成具体动作（`双手交叠放在膝上`），
  给模型一个明确的目标姿态；**② 不想让手出现就一个字都别提**。
  眼睛的对称写法见 `05` 的「数量与对称」一节（那条是描述光学事实，和"要求别崩"不是一回事）
- ⚠️ 用户说的是 **"3D 动漫"** 时不走这一族，走下面的 **族 4b**（这是两族的交叉，单列了）

## 族 4b · 3D 动漫 / CG 角色（族 4 × 族 6 的交叉）

**"3D 动漫"和"CG 游戏角色"是中文用户的高频说法，但族 4 只讲 2D 线条、族 6 只讲产品渲染器，
交叉地带原本是空白。** 这一族专门管它。

### ⛔⛔ 第一步：先问「卡通化」还是「写实化」—— 这是第一层分叉

**这一问不问，后面全错。** 用户说"CG 游戏风格"时，他可能想要的是**完全相反的两种东西**：

| | **卡通化** | **写实化** |
|---|---|---|
| 参考 | 《双城之战》/ 原神 / 塞尔达 | 《黑神话：悟空》/《最后生还者》/《战神》|
| 造型 | 二次元或卡通化比例 | **真实的人体比例** |
| 皮肤 | 纯色块 / 次表面散射透红 | **真实皮肤：可见毛孔、次表面散射、自然高光过渡** |
| 头发 | 块面 / 蓬松绒毛 | **根根分明的真实毛发** |
| 描边 | 有（卡渲）或没有（欧美动画）| ⛔ **完全没有** —— 描边是卡通最直观的标识 |
| → 走 | **下面的支线 A / B** | **支线 C** |

⭐ **判据一句话：这张脸放在真人演员身上，你觉得合理吗？** 合理 → 写实化（C）。
⭐ 用户说「**CG 游戏风格，但不要卡通**」→ **直接走 C**，不要去 A/B 里找。

### 第二步（卡通化）：选支线 A 或 B

⛔ **两条支线的着色逻辑是相反的，不能混，也不能都不选。**

| | 支线 A · 日式卡渲（三渲二）| 支线 B · 欧美 3D 动画电影 |
|---|---|---|
| 参考 | 游戏 CG 角色展示、《双城之战》| 皮克斯 / 迪士尼 / 梦工厂 |
| 造型 | 偏锐利、线条感强、二次元比例 | 圆润、体积感强、卡通化比例 |
| **阴影** | **硬边分界**，只有亮面和暗面两档 | **柔和渐变**，中间调丰富 |
| **高光** | **块状**，边界清楚，不发散 | 弥散、柔和 |
| **皮肤** | **纯色块 + 极简高光**，无毛孔 | **次表面散射**，耳廓和鼻尖透红 |
| **头发** | **块面**（一缕缕硬边块）| **毛发**（根根分明、蓬松） |
| 光 | 硬主光 + 清晰阴影边界 | 柔和全局光照 + 环境反射 |
| 背景 | 大色块 / 纯色 / 简单几何 | 有细节的环境、景深浅 |
| **起手句** | `3D 卡通渲染，赛璐璐着色，阴影边界是清晰的硬边、不是渐变` | `3D 动画电影风格，柔和的全局光照，皮肤有次表面散射的透红感` |

### 支线 A · 日式卡渲（三渲二）· 必须写的三样

1. **着色方式** —— 写 `卡通渲染 / 赛璐璐着色 / cel-shading`，并补一句
   `阴影的边界是清晰的硬边、不是柔和渐变`。⛔ 不补这句会出成写实 3D。
2. **材质简化** —— 写 `头发是一缕缕的块面、不是丝丝分明的毛发`；
   `皮肤是干净的纯色块、没有毛孔和纹理`。
   ⛔ 二次元的核心是**简化**，写"真实皮肤纹理"会直接毁掉风格。
3. **描边** —— 写 `角色外轮廓有一圈细描边线`。这是卡渲最直观的辨识标志。

### 支线 B · 欧美 3D 动画电影 · 必须写的三样

1. **光学特征** —— `柔和的全局光照` + `皮肤有次表面散射的透红感`
2. **材质丰富度** —— `布料有绒毛感、毛发布满蓬松的细丝`
3. **景深** —— `浅景深，背景柔和虚化`

### 支线 C · 写实 CG 游戏角色（次世代 PBR 渲染）

**适用**：用户说「CG 游戏风格但不要卡通」「写实游戏角色」「3A 游戏人物」「次世代建模」。
**参考**：《黑神话：悟空》/《最后生还者》/《战神》。

⛔ **先记三条禁令**（这是写实支线最常被污染的地方）：
- ⛔ **不要描边线** —— 描边是卡渲的标识，写实渲染里必须完全没有
- ⛔ **不要赛璐璐 / 硬边阴影** —— 两者直接冲突
- ⛔ **不要"纯色块皮肤"** —— 写实恰恰要看皮肤上的光反应

**必须写的六样：**

```
1. 起手：写实的次世代 3D 游戏角色渲染，真实的人体比例
2. 皮肤：真实的次表面散射，可见的毛孔，额头和颧骨上有自然的高光过渡
3. 毛发：根根分明的真实毛发，每一缕都能看见单独的发丝，有蓬松的体积
4. 眼睛：虹膜有真实的纹理，眼球表面有一层湿润的镜面反光
5. 布料：织物能看见经纬纹理，褶皱随身体的形状自然垂下
6. 硬质件：金属部件映出周围环境的反射
```

⭐ **"真实"要靠"光打在皮肤上的反应"来写，不是靠堆"真实"两个字。**
写实渲染的看点就是这一层 —— 所以**这一支线需要的是有方向的光，不是均匀平光**。

#### ⭐ 卡渲 ↔ 写实的逐条转换清单（改方向时照这个改，不要重写）

| 卡渲版 | 写实版 |
|---|---|
| `3D 卡通渲染的日式游戏角色风格` | `写实的次世代 3D 游戏角色渲染，真实的人体比例` |
| `阴影的边界是清晰的硬边` | **删**（写实里不能有硬边阴影）|
| `头发是一缕缕的块面` | → `根根分明的真实毛发，每缕可见单独细发丝 + 蓬松体积` |
| `皮肤是干净的纯色块、没有毛孔和纹理` | → `真实次表面散射 + 可见毛孔 + 额头颧骨自然高光过渡` |
| `外轮廓有一圈细描边线` | **删**（描边是卡渲最直观的标识）|
| —— | **补** 眼睛：虹膜真实纹理 + 眼球表面湿润镜面反光 |
| —— | **补** 布料：织物经纬纹理 + 随身体垂下的褶皱 |
| —— | **补** 金属：剑鞘部件映出周围环境的反射 |

⚠️ **两个真实存在的张力，遇到时按下面的建议试，不要放弃**：

**① 写实渲染 × 三视图的均匀平光** ——
平光 = 没有明暗层次 = 没有体积 = **皮肤看起来像塑料膜**，而写实渲染的看点恰恰是光在皮肤上的反应。
→ **正解可能是「棚拍三点光 + 把补光开到接近 1:1 光比」**：
一盏柔光主灯（左前 45°）+ 大面积柔和补光 + 背景轮廓光 ——
阴影很浅、结构仍看得清，皮肤有正确体积。（见 `01` 的「技术图」一节）

**② 写实渲染 × 小景别的皮肤细节** ——
写实皮肤越近越难做，**半身以上的景别比面部特写更容易成功**。

### ⛔ 常见崩法（写错了会得到四不像）

| 崩法 | 症状 | 原因 |
|---|---|---|
| 只写「3D 动漫」 | 出成塑料感的写实 3D，或糊掉的 2D 平涂 | 模型在写实 3D 和 2D 之间随机选，**必须指定支线** |
| 说「CG 游戏风格，不要卡通」但没走支线 C | 出来的**还是卡通** | 没问"卡通化 / 写实化"这一层分叉 |
| 写实支线里写了「描边」| 四不像 | **描边是卡渲最直观的标识**，写实必须完全没有 |
| 写实支线里写了「纯色块皮肤」| 退回卡渲 | 写实恰恰要看皮肤上的光反应 |
| 卡渲 +「真实皮肤纹理」| 皮肤上冒出写实毛孔，风格崩 | 二次元要简化，与纹理描述直接冲突 |
| 卡渲 +「柔和的皮肤反光」| 退回写实 3D | 要写**块状高光**，不是柔和反光 |
| 欧美线 +「赛璐璐 / 硬边阴影」| 退回日式卡渲 | 两条支线的阴影逻辑相反 |
| 「3D 动漫」+「Octane 渲染」| 出成产品渲染质感 | 渲染器词会把画面拉向写实产品图（见族 6）|

⭐ **等距卡通渲染**（isometric cel-shading）是游戏界的常见变体，
配 1:1 或 4:3 画幅、纯色背景最稳。

## 族 5 · 国风 / 东方

**适用**：中国风、汉服、水墨、神话、节气、传统文化
**起手句**：`东方美学，[技法]风格，留白构图`

| 子方向 | 关键补充 |
|---|---|
| 水墨山水 | 散点透视、墨色由深至浅、大量留白、云雾分层 —— ⚠️ **光照槽要替换成墨色层次**，见 `01` 的「绘画形式类」|
| 工笔重彩 | 线条精细、设色浓丽、有金线或描边 |
| 国潮插画 | 平面色块 + 传统纹样 + 现代配色（高饱和）|
| 敦煌 / 唐卡 | 矿物色、对称、装饰性边框、金箔 |
| 宋画 | 淡雅、局部特写、绢本质感 |
| 汉服人像 | 服装形制要写清（曲裾 / 齐胸 / 圆领袍），否则会出成和服或韩服 |

⛔ **国风最容易崩的是服装形制**：只写"古装"会随机出成影楼风或和服。
必须点明具体形制 + 朝代，或直接写 `汉服 / 唐装 / 旗袍`（词表里有）。

## 族 6 · 3D / 渲染

**适用**：产品渲染、IP 形象、盲盒、等距插画、C4D 风
**起手句**：`3D 渲染，[渲染器]渲染，[材质]材质，柔和棚光`

- 渲染器是**独立于风格的第二个轴**，只能写一个：`Octane / C4D / 影视级光线追踪 / Arnold / V-Ray`
  ⚠️ **「卡通渲染」不是产品渲染器** —— 它是动漫的着色方式，属于 **族 4b（3D 动漫）**，
  不要列进这一族，两者混用会出成塑料质感的四不像
- 材质必须写：磨砂塑料 / 陶瓷 / 亚克力 / 金属拉丝 / 半透明果冻
- 等距视角（isometric）是独立构图族，配 1:1 或 4:3 最稳

## 族 7 · 设计 / 海报

**适用**：海报、KV、封面、专辑、社媒图
**起手句**：`平面设计海报，[版式]布局，[配色]配色，留出标题区域`

| 子方向 | 关键补充 |
|---|---|
| 瑞士国际主义 | 网格、大量负空间、无衬线字、极简 |
| 包豪斯 | 几何基本形、原色、不对称平衡 |
| 波普 | 高饱和、网点、重复元素、粗描边 |
| Y2K / 千禧 | 金属银、渐变、立体字、星星元素 |
| 蒸汽波 / 合成波 | 紫粉蓝渐变、网格地面、雕像、落日 |
| 孟菲斯 | 撞色几何、波浪线、活泼 |

### ⛔ 海报类必问的三件事

```
① 主打什么（主体 —— 见 SKILL.md「画面类型 ≠ 主体」）
② 画幅
③ 要不要文字，要的话文字是什么、留白区在哪
```

⛔ **海报类必须写清"文字区域留白在哪"**，否则文字会和主体重叠。
⭐ **文字直接给**：确切的字 + 位置 + 字体形态 + 层级（主副标题的字高比例）——
现在的模型中文渲染已经很稳，**不要劝用户后期叠字**，见 `04` 的「画面里的文字」。

### ⭐ 「空间氛围」类海报：把「墙面」当留白区

**上方三分之一设成一整面被光照亮的浅色墙**（只有很淡的光的渐变、没有别的细节）——
**一次干三件事**：

1. 当标题留白区
2. 满足"背景少而大"
3. 当那片"自己在发光的介质"

⭐ **这比"让人和物避开文字"更省事，也更像真海报** ——
真海报的留白从来不是"空着的地方"，是**被设计出来的一片墙 / 一片天**。

## 族 8 · 材质 / 实验

**适用**：创意概念、社媒吸睛图、专辑封面
**起手句**：`[主体]由[材质]构成，[光线]照射`

可用材质（`07` 的 质量/材质 有 74 条）：玻璃 / 金属 / 纸艺 / 剪纸 / 衍纸 / 刺绣 / 针织 /
毛毡 / 液态 / 生物发光 / 镀铬 / 大理石 / 琥珀 / 陶瓷 / 亚克力

- 玻璃 / 透明材质：**必须写光从背后透过来**，否则会成一坨浑浊的半透明块
- 金属 / 镀铬：**必须有环境反射**，写清反射里有什么
- 纸艺 / 剪纸：**必须写边缘的投影和层叠厚度**

## 族 9 · 绘画传统

**适用**：艺术感、复古、手绘质感、装饰画
**起手句**：`[画种]，[笔触]笔触，[纸/布]底`

可写画种（`07` 的 风格/形式 有 106 条）：油画 / 水彩 / 丙烯 / 水粉 / 粉彩 / 炭笔 /
石墨 / 铅笔 / 马克笔 / 彩色铅笔 / 版画 / 木刻 / 丝网印刷 / 浮雕 / 马赛克 / 彩色玻璃 / 壁画 / 挂毯

⛔ **画种必须配底材**："油画"配"亚麻画布纹理"，"水彩"配"粗纹水彩纸"，否则会出成数码图。

⚠️ **这一族和第 5 族的水墨同属"绘画形式类"** —— 走这一族时，
**光照槽要替换成介质本身的层次**（墨色 / 笔触 / 颜料厚度），不是填光位。
见 `01` 的「绘画形式类」一节。

## 族 10 · 概念 / 科幻 / 幻想

**适用**：世界观设定、游戏概念图、赛博朋克、废土、奇幻
**起手句**：`概念设定图，[世界观]，[画幅] 横幅，大景深`

| 子方向 | 关键补充 |
|---|---|
| 赛博朋克 | 青蓝冷调 + 暖橘霓虹补色、湿地面反光、高密度招牌 |
| 蒸汽朋克 | 黄铜 + 皮革 + 蒸汽、齿轮结构、暖褐主色 |
| 废土 / 末世 | 沙尘、低饱和、破败工业结构 |
| 黑暗奇幻 | 低照度、单一光源、雾 |
| 太空 / 科幻 | 冷调、体积光、巨大尺度的对比 |

⛔ 概念图 **不要只写氛围词**，要写清"这个世界是靠什么运转的"（能源 / 建筑逻辑 / 交通），
模型要靠这些具体物象才能搭出可信的空间。

## 混风格：能混的和不能混的

| 可以混 | 例子 |
|---|---|
| 画种 × 主题 | 水墨画 × 赛博朋克城市 → 水墨风的未来都市 |
| 材质 × 主体 | 玻璃 × 花朵 → 玻璃花 |
| 年代 × 题材 | 80 年代动画 × 桌面游戏 |

| ⛔ 不能混 | 原因 |
|---|---|
| 多个成像系统 | CCD + 胶片 + 棚拍 → 说不清这是什么照片 |
| 多个渲染器 | Octane + C4D → 模型随机挑一个 |
| 互斥的画种 | 油画 + 像素艺术 → 冲突 |
| 多个强烈风格参照 | 宫崎骏 + 赛博朋克 + 莫奈 → 三个方向互相抵消 |

⭐ **一张图只定一个"成立点"**：这张靠什么撑住（场景+镜头 / 光线+妆面 / 道具+光 / 成像方式+场景）。
定了之后，风格表里其余东西**允许留白** —— 什么都上满会亲手做出同质化，
而且一批里第二张就开始退化成默认值（动作和机位最先退化）。
