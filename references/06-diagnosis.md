# 06 · 症状诊断表

**出图不对时，不要重写整条提示词。** 从症状进表，定位到具体哪一槽出了问题，只改那一槽。

⛔ **改了三版还没动 → 卡的是结构不是措辞。** 换景别 / 换画幅 / 换概念，
不要再磨字词（见 03 末尾"先动构图，还是换概念"）。

---

## 一、⛔⛔ 先说最要紧的：用户说「这不是我要的」时怎么办

**这时候不要改措辞。** 先做一件事：**把用户的参考图（如果有）和产出并排，从这五层逐层核**，
找出**第一层开始分岔**的地方 —— 那里才是要改的，改它一层就够。

| 层 | 核什么 | 分岔了怎么办 |
|---|---|---|
| **1 画面类型** | 是亲密特写、半身、环境人像、还是风光？ | ⛔ 到这一层就分岔 → **重出**，不要改词。回 SKILL.md 起手第二步重问 |
| **2 主体占比** | 人在画面里占多大？脸占多大？ | 差一档以上 → 改景别 + 画幅（见 `03` 第 0 步）|
| **3 脸可不可辨** | 能不能看清表情？是不是剪影？ | 剪影/背影 → 换光位（见 `03` 第 1 步剪影的代价）|
| **4 色调** | 冷调还是暖调？饱和度高低？ | 反了就换主色温（见 `03` 第 5 步）|
| **5 介质** | 雾、雪、雨、尘、光斑 —— 是点状还是面状？ | 换介质，或改介质的密度 |

⭐ **前三层是"结构"，后两层是"参数"。结构错了改参数永远改不动**（见本文件末尾"结构类"）。

### 实战示例：为什么"朦胧感"会出成完全不同的两张图

| | 用户要的 | 实际给的 | 第几层分岔 |
|---|---|---|---|
| 画面类型 | 亲密特写 | 环境人像 | **第 1 层** ← 病根在这 |
| 主体占比 | 两张脸占满画面 | 21:9 里两个小剪影 | 第 2 层 |
| 脸 | 清晰、有表情 | 纯黑剪影，看不见 | 第 3 层 |
| 色调 | 蓝灰冷调低饱和 | 暖金主导 | 第 4 层 |
| 介质 | 雪（点状、疏）| 雾（面状、满屏）| 第 5 层 |

**五层全错，但只需要修第 1 层。** 第 1 层修了，后面四层会自动跟着走
（亲密特写 → 人占满 → 必须打脸光 → 色调可单独定 → 介质改成薄霭）。

⛔ **反过来做（从第 5 层往上改措辞）会改十版还是不对** ——
因为第 1 层的画面类型已经定了，后面所有词都在服务一个错的框架。

## 二、验收清单（只用肉眼，两组分开）

**第一组：东西对不对（画幅、元素、构图）**

1. 画幅和景别匹配吗？特写在 16:9 里做不出来。
2. 提到的每个身体部位 / 服装件，在画框里吗？不在的会被模型自己编出来。
3. 主体够不够大？人物脸占画幅 < 1/5 → 换景别或换画幅。
4. 画面里有几个色温？只有一个 → 见第 5 槽。
5. 光源实体在画面里吗？看得见光是从哪来的吗？
6. **有没有一块真正的黑？**⚠️ 这条**只在画面发灰发闷时才查** ——
   高调 / 明亮的图**不需要黑锚**，硬加会压暗画面（见 `05` 的「影调」一节）。
7. 主体有没有重复穿同一件 / 用同一个道具？
8. ⛔ **用户说过的硬信息落地了吗？** —— 性别 / 人数 / 年龄段 / 种族 / 关系。
   把提示词里的每个"两个人 / 对方 / 他 / 她"换成本来的身份，看信息还在不在。

**第二组：好不好看（⛔ 第一组全过也可能这组全废）**

8. **背景是"少而大"还是"细碎堆叠"？找得出一条贯穿画面的线吗？**
9. **主体上有没有明确的亮面**（分得出亮面和暗面，不是均匀的环境光）？
10. 有没有**一大片东西自己在发光**？冷色够不够大够不够艳？
11. 是想"唯美氛围"还是"主体好看"？这两个对光位的要求相反。
12. **（双人图）两个人的关系读得出来吗？** —— 身体朝向、视线有没有交叉、焦平面分层了没有。
    ⛔ 三样都没有 = 影楼合影，光再对也救不回来。

**第三组（只在画面类型是「人物设定 / 技术图」时查）**

1. **格数和排布对吗？** 从左到右数一遍：面部特写 → 正面 → 侧面 → 背面。
   ⛔ 出现"四个全身"或"少一格特写"→ 见 `01` 的「A · 人物设定」。
2. **四格是同一个人吗？** 发色 / 发型 / 瞳色 / 服装每个部件 / 头身比，逐条对。
3. **背视图认得出是谁吗？** 看不到脸 —— 只能靠发型背影和服装背面。
4. **光照是均匀平光吗？** 有没有戏剧性明暗、有没有方向性投影。
5. **背景是同一个纯色吗？** 四格比一遍，有没有哪格冒出了环境。
6. **全清晰吗？** 有没有景深把后面的格虚化掉。

**组图多问一句**：十张摆在一起，像不像同一张？按 03 的六个轴数一遍
（景别 / 光位 / 场地 / 主光色温 / 动作骨架 / 机位）。

## 四、三条诊断纪律

1. **一次只改一槽。** 同时改三处，出图好了也不知道是哪处起的作用，下次还是瞎猜。
2. **先抽 3~8 个种子再判措辞好坏。**
   同提示词换种子的摆幅**盖得过整个措辞轴** —— 实测同一批 10 条提示词跑两个种子，
   一个种子挑中 7 条，另一个 10 条全毙。**别拿单张判断措辞好坏。**
3. **数值只能证伪，不能证真。** 亮度分位、过曝占比、锐度方差这些指标可以抓爆掉的图，
   但数值最漂亮的那组可能是"主体上一点光都没有的好看背景板"。
   **唯一可靠的验收是肉眼看。**
