# 05 · 质量词与约束写法

三件事：**画质词什么时候加**、**柔化效果怎么实现**、**"不要 X"该怎么写**。

---

## 一、画质词：不是"无效"，是"有害"

| 模型类型 | 加不加 | 原因 |
|---|---|---|
| **GPT-Image-2 / 2.5** | ⛔⛔ **绝对不能加** | **anti-slop**：`stunning / epic / masterpiece / 8K / trending on artstation` 会**让结果变差**，不只是无效 |
| 即梦 / 豆包 / 通义 / Seedream | ⛔ 默认不加 | 默认就在出高清图；这类词挤占字数预算，不加分 |
| Nano Banana | ⛔ 不加 | 忽略这类词 |
| SD / ComfyUI | ✅ 加一行 | 通用正/负向词在 `07` 的"附：SD 通用正/负面词"，直接抄 |
| Midjourney | ⭕ 视情况 | 用 `--stylize` 代替画质词，不是堆形容词 |

### ⭐ 用「规格语言」替换「赞美语言」

**赞美词告诉模型的东西是零，还会把画面推向图库广告感。**
规格词告诉模型东西放在哪、长什么样。

| ⛔ 赞美语言 | ✅ 规格语言 |
|---|---|
| 绝美的光 / 完美的打光 | 柔和的北向窗光从左侧来，带一点环绕补光 |
| 专业感 / 高级感 | 单一强调色 #6366F1，8px 网格间距 |
| 高质量 / 高清 | 浅景深，50mm 的观感，中性白平衡 |
| 细节丰富 | 陶瓷釉面有可见的不均匀，台面有细木纹 |
| 质感很强 | 杯壁有细微的釉面光泽 / 面料是粗纺亚麻、能看到经纬线 |
| 现代感 | 平面矢量，2px 等宽描边，大量留白，米白背景 |
| 光影绝美 | 麦穗影子在桌面上细长而清晰 |

⛔ **要质感就写具体材质和具体表面**，不要写"质感很强"。

### 镜头参数：按模型决定写法

| 模型 | 镜头参数 |
|---|---|
| **Nano Banana** | ⛔ **不要写数字**（`50mm` / `f/2.8` / `ISO 400`）—— 它直接忽略。改成描述性：`浅景深`、`长焦压缩感` |
| **GPT-Image-2 / 2.5** | ⚠️ `50mm` 这类数字只当**高层观感**接受，**不是精确的光学模拟**。写 `50mm 的观感` 可以，别指望它真按 50mm 成像 |
| **即梦 / 豆包 / 通义** | 写**感觉**不写数字：`浅景深` / `广角的透视拉伸` / `贴近拍摄的近距离感` |

⭐ **通用做法：一律把数字改成语感描述。** 这样在任何模型上都不会错。

⭐ **材质词库**在 `07` 的 质量/材质：铝合金 / 砖块 / 铜质 / 陶瓷 / 磨砂 / 亚克力 / 大理石 / 玻璃 / 刺绣 / 针织 / 毛毡 / 生物发光 / 镀铬 / 琥珀 ……
写材质时**必须同时写"光照上去是什么样"**，只写材质名会出成塑料：
- 玻璃 → ⭐ **有两条分路，按影调选**（见下）
- 金属 → `映出周围环境的反射`
- 纸艺 / 剪纸 → `边缘的投影和层叠厚度`

#### ⭐ 玻璃的两条分路（按影调选）

| 分路 | 写法 | 用在 |
|---|---|---|
| **暗场打光** | 深背景 + 亮轮廓；光穿过瓶身把液体从内部点亮，从正面向外透出暖光 | 低调 / 氛围 |
| **亮场打光**（bright field）| **在瓶子背后打一片发亮的白**，让光从前方向后穿过瓶身 → 瓶身自然浮出**两条深色的竖轮廓线** | 高调 / 白底产品 |

⛔ **「玻璃 + 高调」是风险组合** —— 白瓶子放在白背景上会被洗掉、轮廓消失。
⭐ **亮场打光是"白底拍玻璃"的正解，不是靠加描边硬画。**

⭐ **「商业广告图 + 高调」的调和写法**：
广告图要明确光向性（否则产品是平的），高调要大片散射 →
用「**大面积柔和的环境光 + 一束从侧后方穿瓶而过的柔光**」同时满足。

⭐ **广告图不加浅景深** —— 它需要场景细节和清晰材质，虚化会把质感吃掉
（⚠️ 这一条和小景别摄影的默认**相反**）。

### 微观细节层 —— 要加质感时从这里挑，不要发明形容词

**这是"质感不强"的正解**：不是加形容词，是**往下钻一层**。
只在"详尽 / 电影级"档才用（见 `04` 的 Detail Mode），**一次挑 2~3 类就够，不要全上**。

| 层 | 写法示例 |
|---|---|
| **1 表面磨损与老化** | 窗框上剥落的漆、金属表面的细划痕、铜件上的绿锈、铁铰链的氧化痕 |
| **2 微观纹理** | 皮肤上可见的毛孔、逆光里根根分明的发丝、亚麻衬衫的织纹、旧木头的木纹 |
| **3 空气粒子** | 光柱里悬浮的尘埃、咖啡杯升起的水汽、空气里的花粉、玻璃上的细水珠 |
| **4 高光行为** | 金属边缘的镜面高光、玻璃瓶里晃动的水光、雨后石板的湿润反光 |
| **5 布料垂坠** | 手肘处自然的褶皱、宽松亚麻的重力拉伸、厚羊毛大衣的重量分布 |
| **6 接触阴影** | 杯底与碟子之间的软阴影、石墙缝隙里的环境闭塞、书脊与桌面的暗线 |
| **7 环境反射** | 湿路面上映出的建筑、镀铬表面上的天空渐变、招牌在皮肤上的暖色照映 |
| **8 运动痕迹** | 发梢的轻微拖影、咖啡落下时凝固的水滴、围巾被风吹起的一角 |

⭐ **八类里挑最贴合这张图的 2~3 类**。上满会互相打架，而且会把画面推向"技术展示"。
⭐ 这一层的正确用法：**先想这张图的成立点是什么，只加能强化那个成立点的细节。**

## 二、柔化 / 朦胧效果：怎么让画面**真的软下来**

⛔⛔ **最关键的一条事实：「柔焦」这个词本身几乎零效果。**
实测五档柔焦写法（`柔焦` / `soft focus` / `朦胧` / `轻微失焦` / `柔和虚化`），
**画面锐度不降反升** —— 模型会把它理解成"更细腻"，反而画得更清楚。

⭐ **所以用户说"朦胧感 / 柔化 / 空气感"时，不要写"柔焦"两个字就交差。** 有三条真有效的路径：

### 三条有效路径（按有效性排序）

| 路径 | 怎么写 | 有效性 |
|---|---|---|
| **① 加介质**（最有效）| 在场景句里塞进**挡在镜头和主体之间的东西**：一层薄雾 / 空气里的水汽 / 飘动的薄纱 / 玻璃上的雾气 / 前景的失焦枝叶 | ⭐⭐ 实测能把锐度真的压下来 |
| **② 换成像系统** | 写 `柔光镜 / 黑柔滤镜 / Pro-Mist` 这类**实拍滤镜**；或 `老镜头的低对比` | ⭐ 有效，属于成像系统层面（一张图只能有一个，见 02）|
| **③ 压低对比 + 让高光溢出** | `高光不到纯白，最亮的部分是一片化开的灰白，没有锐利的边缘` | ⭐ 有效，配合 ①② 用 |

### ⛔ 柔化最怕的两件事

**① 把脸一起糊掉。** 柔化必须和"主体保持清晰"配套写：

```
柔化只作用在画面边缘和高光上，人物面部保持清晰；
最亮的地方晕开一层淡淡的光晕，没有硬边。
```

**② 写成"失焦"** —— 那是画质问题不是氛围。要写**"柔而不糊、边缘晕开但结构完整"**。

### 柔化程度分档

| 档 | 写法 | 用在 |
|---|---|---|
| **轻微** | `画面边缘有一层很淡的晕开感，主体完全清晰` | 想要干净但有空气感 |
| **中等** | `整体像隔着一层薄纱拍的，高光化开，面部仍能看清细节` | 大多数"朦胧 / 氛围"需求 |
| **较重** | `空气里有一层可见的水汽，远处的高光连成一片发白的雾` | 梦境感、记忆感 |

⭐ **判据：柔化是为了让画面有空气，不是为了看不清。** 主体该清楚的必须清楚。

⚠️ **后期兜底**：如果试了上面三条还是不软，**不要继续改词** ——
直接后期加 bloom / 高斯模糊（保留主体蒙版）。**提示词层面的柔化能力是有上限的。**

## 三、⛔⛔ 「亮」和「美」是两个独立的轴（本节最重要）

**治暗的时候最容易犯的错：为了把画面提亮，换成均匀光 —— 结果脸平了，人就不美了。**

⛔⛔ **"画面整体亮度"和"脸部的明暗结构"是两件不同的事。**
- **画面整体亮度** = 曝光。这个可以调高，治"暗"就在这里治
- **脸部明暗结构** = 立体感（亮面 + 暗面）。**这个绝不能因为治暗而被抹平**

| 做法 | 结果 |
|---|---|
| ✅ 提高整体曝光，**保留主光方向和脸上的亮暗面** | 明亮**且**立体 —— 又亮又美 |
| ❌ 换成"大面积散射光 / 均匀柔光"把暗部抹掉 | 亮了，但**脸平 → 不美**（`03` 第 1 步已明令禁止均匀光）|

⭐ **原话**：写"柔和地照亮她的脸" = 均匀光 = 等于没打。

⭐ **"被暗部托着"本身就是美的来源** —— 明亮的正面光会把脸的所有起伏平铺出来；
**只有轮廓和高光是亮的、其余落在暗部里，同一张脸立刻上一个台阶。**

### 正确的"治暗"写法（三件事，都不动明暗结构）

```
1. 整体曝光正常偏亮，画面大部分是亮的、通透的      ← 治暗在这里
2. 暗部是浅灰、不是黑（暗部里仍有层次和细节）      ← 治暗在这里
3. 主光仍有明确方向，脸上仍有亮面和暗面            ← ⛔ 这一条不许动
```

⛔ **不要用"大面积散射光 / 均匀柔光 / 无方向补光"来治暗** —— 那是拿美感换亮度。
✅ 保留"单一主光 + 明确的侧前 / 正前偏下方向"，只把**曝光**和**暗部亮度**提上去。

## 四、人像真实感：怎么让人不「假」

⛔ 用户说「人像有点假 / 表情假」时查这一节。**先分清他要的是「美」还是「真」** ——
这两个目标在皮肤和结构上的写法是**相反**的。

| | **美（默认）** | **真 / 纪实** |
|---|---|---|
| 皮肤 | 干净通透、有自然反光的层次 | 保留毛孔、细纹、可见的色差 |
| 结构 | 五官精致、脸型流畅 | 有不对称、法令纹、痣或浅疤 |
| 毛孔 / 皱纹 | ⛔ **不加** | ✅ 要写 |
| 适用 | 写真 / 氛围 / 商业 / 美妆 / 古风 | 人文纪实 / 街头 / 年代感 / 素人感 |

⭐ **默认走「美」。** 用户没说要"素人感 / 纪实感 / 不要磨皮"时，**不要主动加法令纹和不对称** ——
那是拿美感换真实感。

### ⛔ 关键修正：塑料感的三个真正成因

**"假"的原因不是"脸太完美"，而是这三件事。治它们都不需要牺牲美：**

| 成因 | 治法 | 会影响美吗 |
|---|---|---|
| **① 表情死板**（最常见）| 表情拆成动作 + 眼睛有戏 | ✅ 反而更美 |
| **② 皮肤反射像塑料** | 写对反射（半哑光 + T 区窄高光）| ✅ 反而更美 |
| **③ 光平、没立体感** | 亮面 + 暗面 + 三角亮斑 | ✅ 反而更美 |

⛔⛔ **不要去写"法令纹 / 不对称 / 痣 / 疤"来治塑料感** ——
**那是"纪实"配方，不是"防塑料"配方。** 美人像加了这些会直接掉一个档。

### ① 表情是"摆出来的"（最常见的原因）

⛔ **写「微笑」「开心」「温柔」这种笼统词 → 出来的是"嘴角上扬但眼睛没笑"的标准 AI 假笑。**

✅ **拆成「肌肉动作 + 幅度 + 眼神」：**

| ⛔ 笼统词 | ✅ 拆成可观察的动作 |
|---|---|
| 微笑 | 嘴角微微上扬，**眼睛跟着一起弯起来**，眼下皮肤有浅浅的纹路 |
| 大笑 | 露齿笑，嘴角向两侧拉开、脸颊鼓起、**眼睛眯成一条缝**、眼角有细纹 |
| 温柔地看着 | 目光落在对方脸上、眼神放松、眉尾微微下垂、嘴唇自然闭合 |
| 忧郁 | 视线向下、眉间有很浅的竖纹、嘴唇抿成一条平线 |
| 惊讶 | 眉毛抬起、眼睛睁大、嘴唇微张成一个小圆 |

⭐⭐ **判据：笑的真假全在眼睛。** 只写嘴角 = 必然假笑。
**任何表情都必须同时写"眼睛在做什么"** —— 这是这一条里唯一不能省的东西。

⭐ **有情绪的瞬间比"标准表情"更美**：
`眼睛半垂着、睫毛在眼下投出浅影` 比 `美丽的眼睛` 有味道得多。

### ② 皮肤的光写对（防塑料感的正解）

皮肤**纹理**和皮肤**反射**是两个独立的轴（见本文件「几个高频"要压制的东西"怎么改写」一节）。
只写毛孔 → 得到「**有毛孔的油亮皮肤**」，比原来更假。

⭐ **美容向固定写法**（写完直接提升质感，不用加任何"瑕疵"）：
```
自然半哑光底妆，额头与双颊是柔和的漫反射，T 区只有一条克制的高光，
皮肤的质感是干净通透的，不是塑料感的反光
```

### ③ 立体感靠光，不靠加瑕疵

⭐ 美人像的立体感**全部来自光**，来自 `03` 第 1 步的**打脸四件套**：
亮面 + 暗面 + 鼻侧的三角亮斑 + 睫毛投在被照亮那半边脸颊上的影子。

⛔ **脸平 = 不美，但解法是补光，不是补瑕疵。**

### ④ 成像系统选错

⭐ 实测"最像真照片"的两档：**中长焦 85mm 数码** 和 **VHS 录像带**（泛朦低对比反而掩盖 AI 感）。
⚠️ `CCD 直闪` 只在「这个场景现实里真会有人开闪光灯」时才成立。
⛔ 一张图只能有一个成像系统，混用会说不清这是什么照片（见 `02` 族 1）。

### ⭐ 美人像四件套（写实人物近景 / 特写默认写这套）

```
表情：嘴角微微上扬，眼睛跟着一起弯起来
眼神：目光落在[某个具体的东西]上，两只眼睛里各有一小点自然的反光
皮肤：皮肤干净通透、有自然的柔光层次，T 区只有一条克制的高光
光泽：额头、颧骨和鼻梁被照亮，鼻侧留一小块三角亮斑，另外半张脸落在柔和的暗部里
```

⚠️ **前三条是"防假"，第四条是"美"** —— 四条一起写才既真又美。

### ⛔ 只在纪实题材用（不要默认加）

```
保留真实的毛孔和细纹，鼻翼两侧有自然的法令纹，左颊有一颗很小的痣
脸型不是完美的椭圆，一边眉梢比另一边略高
```

⭐ **判据：用户说了「素人感 / 纪实 / 年代感 / 不要磨皮 / 真实感强」才用这套。**
否则默认走「美人像四件套」。

## 五、影调（明暗基调）—— 曾经缺失的一槽

⛔ **早期版本只有"色彩（冷暖）"没有"影调（明暗）"，结果图全都往低调跑。**
用户说"朦胧 / 氛围 / 高级"≠ 要暗。**这两件事必须分开定。**

| 影调 | 特征 | 用在哪 |
|---|---|---|
| **高调 High-key** | 亮、轻、通透，阴影很浅甚至没有，大部分画面是亮的 | 清爽 / 日系 / 少女 / 护肤 / 简约产品 / 白底 |
| **中间调** | 正常曝光，有亮有暗但不极端 | ⭐ **默认档**（用户没说时用这个）|
| **低调 Low-key** | 暗、重、戏剧性，大面积阴影，只有一小块亮 | 情绪 / 悬疑 / 高级感 / 酒类 / 男性向 |

⭐ **默认给中间调，不要默认低调。** 只有用户明确说"暗调 / 情绪感 / 高级感 / 电影感"才走低调。

### 要亮起来，写这四样

```
1. 整体曝光正常偏亮，画面大部分是亮的、通透的
2. 暗部是浅灰、不是黑（暗部里仍然有层次和细节）
3. 白平衡中性或略暖，避免全画面冷灰
4. ⛔ 主光仍有明确方向，主体仍有亮面和暗面 —— 这一条不许动（见本节上文「亮和美是两个独立的轴」）
```

⛔⛔ **第 4 条是关键。** 提亮画面**不等于**把光变成均匀光 ——
`大面积散射光 / 均匀柔光 / 无方向补光` 会把脸照平，**亮度上去了、美感下来了**。
✅ 保留明暗结构，只提**曝光**和**暗部亮度**。

### ⭐ 高调在「天然低调场景」里怎么成立

**夜景、雾天、夜晚室内 —— 这些场景天生是低调的。**
硬提亮只会得到一张灰扑扑的假白天。**正解不是提亮，是换一个"让画面亮起来的机制"：**

| 场景类型 | 高调靠什么成立 | 机制 |
|---|---|---|
| **夜景 / 雾** | **浓雾把灯光散成一整团发亮的介质** | 光被介质吸收后二次发射，背景从黑变成发亮的灰白 |
| **雪后 / 雨后天光** | ⭐ **积雪本身就是超大反光板** | 地面把所有光反弹回来 → 阴影自然是浅灰、不是黑 |
| **室内** | 窗户光作大面积散射 | 常规方案（见上）|

⭐⭐ **「高调 + 夜景」是结构性矛盾，正解是「介质散光」：**
不靠光源本身亮，而是**让雾 / 湿气抱住灯光** ——
光在雾里散成一整团很大的冷白光球 → 整片空气变成"被光照透、自己在发光"的介质
→ **高调成立，背景从黑变成发亮的灰白。**

⭐ **两个附加好处**：① 散射光天然解决顶光问题
② 一次满足 `03` 构图③「发光介质占画幅 ≥ 1/3」。

### ⛔⛔ 高调 + 冷调：必给「一个暖色实体 + 一个黑锚」，缺一个就糊成冷灰

**这两个条件叠加时画面极易糊成一片冷灰** —— 尤其雪景：
白天空 + 白雪地 + 冷调 = **三样同一个颜色**。

| 缺什么 | 补什么 |
|---|---|
| 没有暖色 | **一个暖色实体** —— 一扇亮着的窗 / 一盏没关的灯 / 一枚暖橘的点 |
| 没有重色 | **一个黑锚** |

⭐ **黑锚在"全画面浅色"的场景里必须靠人造物** —— 立柱 / 站牌 / 栏杆 / 电线杆。
自然环境（雪原 / 海面 / 天空）里根本没有黑色的东西。

⭐ **「灯杆 / 站牌立柱」一物四用**（高调图尤其需要它）：
① 光源的实体支架 ② 画面里唯一的竖线（几何线）
③ 光源实体的载体 ④ **高调画面里唯一的一块真黑**

### ⛔ 压低亮度的手段（不要默认用）

`环境压暗` / `大面积阴影` / `低调照明` / `电影感暗调` ——
**这一组词只在用户明确要"暗 / 情绪 / 高级"时才写。** 默认写 = 图必暗。

⚠️ `单一聚光（主光源压暗环境）` **分寸不同**：它是一种**明暗结构**，
人像的立体感要靠它。**要保留方向，但不要把环境压黑。**
正确写法是"一个明确方向的主光 + 环境保持正常亮度"，而不是"单一聚光 + 环境压暗"。

⭐ 最常见的暗调来源其实是**冷调 + 低饱和被当成了默认**。
「蓝灰冷调低饱和」是一套完整的暗调配方，不要不经确认就给。

## 六、约束：先按模型判断，再决定怎么写

### 负向词不是一律失效 —— 按模型分档

⛔ **早期版本这里写着"自然语言类模型都不吃负向词"，那是错的** ——
把 cfg=1 蒸馏模型的经验错套到了所有模型上。**GPT-Image 系列是遵守显式负向的**（官方确认）。

| 模型 | 负向词 | 怎么写 |
|---|---|---|
| **GPT-Image-2 / 2.5** | ✅ **生效** | 可以显式写：`no watermark, no extra text, no logos, no extra fingers` |
| **Midjourney** | ✅ 生效 | `--no plants, text` |
| **SD / ComfyUI（cfg>1）** | ✅ 生效 | 独立负向框，从 5~8 项起 |
| **Nano Banana（Gemini）** | ⛔ 正向化 | 官方口径是正向描述：✅ `clean background` ❌ `no clutter` |
| **cfg=1 蒸馏模型**（Lightning / Turbo / 各类加速模型）| ⛔ **填了不报错，就是不生效** | 只能正向化 |
| **即梦 / 豆包 / 通义 / Seedream** | ⚠️ **不稳** | 默认正向化；要排除时用「正向描述 + 末尾一句排除」双保险 |

⭐ **拿不准就正向化** —— 正向化在任何模型上都不会错，只是啰嗦一点。

⚠️ 而且还有一层：**`没有X` 这句话本身是在召唤 X。** 提示词里出现"树"这个字，
模型就倾向于画树 —— 哪怕前面写的是"没有"。
**所以最稳的做法始终是：把要的东西写死，而不是靠否定。**

### 正向化公式

```
先正面说这块东西「是什么」，再列你要排掉的那一两项
```

| 想要 | ⛔ 写不出来的 | ✅ 正着写 |
|---|---|---|
| 不要投影 | `negative: shadow` | `每个物体都直接贴在白纸上，不产生任何投影` |
| 脸别太圆 | `脸不胖` | `窄长的鹅蛋小脸，脸颊平顺内收、下颌角收窄，下巴是尖的` |
| 皮肤干净 | `无瑕 / 没有痘` | `脸颊、下巴和嘴角是连续平整的一片皮肤` |
| 不要腮红 | `没有腮红` | `两边脸颊和鼻梁是和额头、下巴连续的同一片自然肤色，没有腮红、没有额外的红晕或色块` |
| 短裙别变连体衣 | `不是连体衣` | `裙筒是完整闭合的一圈、四周一样齐地把大腿包住` |
| 丝袜不透明 | `不透明的丝袜` | 换名词：`天鹅绒打底裤袜` |
| 背景别太乱 | `不要杂乱的背景` | `背景是一整面深褐色的墙，只有右上角露出一小块砖墙和它那条笔直的边线，其余没有细节` |
| 不要文字 | `no text` | `画面里没有文字和水印`（这一条是**唯一例外** —— 它属于「输出规格」而不是「画面内容」，实测有效且必要）|

⭐ **最后那条是例外，要记住**：排除文字 / 水印是唯一值得保留的否定句，
因为它指向的不是画面内容而是输出规格。

⭐⭐ **由此得到一条通用判据 —— 收尾句里只放「输出规格」，不放「画面内容」和「部位质量」：**

| 放什么 | 例子 | 为什么 |
|---|---|---|
| ✅ **输出规格** | `画面里只有[主体]` / `没有文字和水印` | 全局属性，写一次就管用 |
| ⛔ **画面内容** | `双手捧着杯子` | 属于主体层，该写在装配顺序的第④位，不是收尾 |
| ⛔⛔ **部位质量要求** | `双手五指完整` / `五官端正` | **反效果**：宣布部位存在 + 把注意力引过去 |

## 七、数量与对称：作用在成对器官上的状态词

⛔⛔ **通则：任何作用在成对器官上的状态词，不钉数量和对称，模型默认只作用在一只上。**
眼睛是最容易踩的（反光、眯、眨、挑眉都算），因为 wink / 单眼反光在训练数据里本身就是常见画面。

| 想要 | ⛔ 写不出来 | ✅ 正着写 |
|---|---|---|
| 眼里反光**两只对称** | `眼睛里有一颗清楚的反光点` | `两只眼睛里各有一小点一样大小、一样位置的暖金色反光` |
| 眯眼**两只一起眯** | `她微微眯起眼看向镜头` | `她两只眼睛一起微微眯着、两边的眼缝一样窄` |
| **故意**只闭一只（wink）| `她冲镜头 wink` | `她只闭上左边那只眼睛、右边那只睁得很大地看向镜头` |
| 两只手都抬起来 | `抬手` | `两只手一起抬到肩膀高度` |

⭐ **"一颗"是数量信息，模型会照做。** 写法上要同时做两件事：
**把数量正着钉成"各一点"**，并把体积**降级**成"一小点"（不要"清楚的反光点"）。

⭐ **别把 wink 当禁区。** 病因从来不是"不能只闭一只眼"，是**没钉是哪只**。
钉死之后 wink 就是个稳定可控的表情。

## 八、几个高频"要压制的东西"怎么改写

这些是 AI 自动补入的东西，往往需要压掉。**一律用正向描写代替否定。**

| 想压掉 | 成因 | 正向化写法 |
|---|---|---|
| 腮红 | 妆容名词自带先验 + 因果句（"被晒红""忍住笑"）| ① 妆容名词换成"很淡的裸妆"；② **带因果的从句整句删掉**，改成中性表情；③ 正向写脸颊肤色 |
| 满面油光 | 只写了皮肤"纹理"，没写"怎么反光" | 皮肤**纹理**和皮肤**反射是两个独立的轴**，必须分开写：`自然半哑光底妆，额头与双颊保持柔和漫反射，T 区只有克制的窄高光，水润质感只保留在唇部` |
| 背景抢戏 | 背景有清晰细节 / 高锐度高微反差 | 分级写：`主体清晰，背景合并成低反差低锐度的色块` |
| 塑料感 | 只写了材质名，没写光照关系 | 补一句光怎么作用在这个材质上 |
| 过度锐化的 AI 感 | 全画面同一档锐度 | `景深、锐度、微反差分区写`；或选胶片 / 录像带这类自带柔化的成像系统 |

⭐⭐ **返工方向有时反直觉**：已经出油腻感了，**先减少覆盖脸部的闪光强度和过曝范围，
再补区域反射**；**不要只去加"真实毛孔、真实纹理"** —— 那样得到的是「有毛孔的油亮皮肤」，
更油。同理，腮红已经在图上了，**再加新措辞句是无效的**，要换场景光位（避免正面强暖光）。

### ⛔ 手的质量不用在收尾句里管（这条改过）

**早期版本把 `双手五指完整` 写成了固定收尾句 —— 已删除，那是反效果的。**
它同时犯了两个错：**① 宣布了"画面里有一双手"**（原本手在画面外也会被硬造出来）；
**② "五指完整"是在念咒**（越强调越容易崩）。现在的模型手部生成已经相当好。

真要处理手的质量，只有两条路：

| 路 | 怎么做 |
|---|---|
| **① 靠景别** | **手占画面越大越可靠** —— 手小或不在画面里，根本不用管 |
| **② 靠具体动作** | `掌心托住杯底，拇指扣在杯沿上` —— 给模型一个明确的目标姿态，比"五指完整"可靠得多 |
| ⛔ 不要 | 加质量要求、反复强调、写"不要畸形" |

⭐ **不想让手出现，就一个字都别提** —— 收尾句不宣布部位，模型就不会硬造。
详见 `04` 的「收尾句不要写身体部位的质量要求」一节。

## 九、质量词参考清单（SD/MJ 用，自然语言类忽略）

按 `07` 的 质量/画质 分类（77 条）取常用，不要照抄一长串：

| 用途 | 词 |
|---|---|
| 通用正向 | `masterpiece, best quality, highly detailed` |
| 真实质感 | `photorealistic, ultra realistic details, realistic skin texture` |
| 通用负向 | `(worst quality:2), (low quality:2), lowres, jpeg artifacts, watermark, signature, text` |
| 人物负向补充 | `bad anatomy, bad hands, missing fingers, extra digits, poorly drawn face, mutated hands` |
| 逼真图专用负向 | `illustration, painting, drawing, sketch` |
| 插画专用负向 | `photorealistic, 3d render` |

⛔ **不要无脑抄长串负向词**。负向词表越长，越容易把你要的东西也一起压掉。
按你实际踩过的坑逐条加，从 5~8 项起。

⚠️⚠️ **别把这里的词抄进自然语言类提示词** —— 两者机制完全不同：

| | SD / MJ 的负向框 | 自然语言类的收尾句 |
|---|---|---|
| 机制 | 数学上的**概率压制**（cfg>1 时真生效）| **纯文本**，模型当内容读 |
| 写 `bad hands` | ✅ 有效，减少手画崩的概率 | ⛔ **等于在提"手"** → 召唤出一双手 |

⭐ **所以「手」的处理原则只有一个：画面里不需要手，就一个字都别提。**
（见 `04` 的「收尾句不要写身体部位的质量要求」）
