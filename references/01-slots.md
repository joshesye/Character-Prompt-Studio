# 01 · 槽位骨架

用户递过来的想法永远是碎片：`一个赛博朋克女孩` / `秋天的森林，要宫崎骏那种感觉` / `给我做个咖啡海报`。
骨架的唯一作用是把碎片补成一个完整画面，并让你知道**该问什么、什么可以不问**。

本文件合并了两套来源（叶子的 Midjourney 8 要素框架 + 通用 7+2 槽模板），
拆成三层十八槽。**每槽都标了必填度和缺省值** —— 缺省值就是"用户不回答时你直接填什么"。

⚠️ **有四类画面要整套反写，不走这套骨架**（人物设定 / 技术图 / 建筑 / 绘画形式类）——
见「特殊画面类型」一节。认出来就直接整套切换。

---

## 一、三层骨架

### A 层 · 主体层

| 槽 | 回答什么 | 必填 | 缺省策略 |
|---|---|---|---|
| A1 主体 | 画面里最主要的是什么（人 / 物 / 景 / 概念）| ✅ 必填 | 问不出来就不动手 —— 没有主体就没有画面 |
| A2 关键特征 | 主体的辨识性特征（外貌、材质、形态、品牌）| ✅ 必填 | **用户明确说过的身份信息必须原样落地**（性别 / 年龄段 / 种族 / 人数 / 关系）；其余由画面类型给一套通用描述 |

#### ⛔⛔ 「中性指代词不携带身份」—— 双人图最隐蔽的丢信息

**中文的 `两个人` / `对方` / `旁边的人` / `他` / `她` 都不携带身份信息。**
你不写清楚，**模型会按先验自己补** —— 而先验不一定是你想要的。

> 用户说「一男一女」，你抽成了 `A1 主体=两个人`，
> 后面一路用"两个人""右边这个""左边的人" —— **性别信息在抽槽那一刻就丢了。**
> 模型拿到的是"两个人"，按先验补出来的是**两个男性**。

⭐ **判据：把提示词里的指代词逐个换成本来的身份，看信息还在不在。**

| ⛔ 信息已丢 | ✅ 身份写实 |
|---|---|
| `两个人坐在长椅上` | `一名年轻女性和一名年轻男性坐在长椅上` |
| `右边这个正看着左边的人笑` | `坐在右边的女性正看着她身边的男性笑` |
| `两个人穿的都是深色上衣` | `她穿深色针织衫，他穿深色衬衫` |

⛔⛔ **而且不能只在开头写一次。** 第一句宣告"一男一女的半身照"、后面全用"两个人" ——
**信息依然会漂**。这和色温 / 影调是同一条道理：**信息要落到具体的句子里，不能只宣告一次。**

⭐ **哪些信息属于「必须落地」的硬信息**（用户说了就一个字都不能丢）：

| 类别 | 例子 |
|---|---|
| **性别** | 一男一女 / 两个女性 / 一对父子 |
| **人数** | 三个人 / 只有一个人（★「只有」也是硬信息）|
| **年龄段** | 老人 / 孩童 / 少年 / 中年 |
| **种族 / 国籍** | 欧美面孔 / 亚洲面孔 / 混血 |
| **物种 / 形态** | 人 / 拟人化动物 / 机械体 |
| **关系** | 恋人 / 母女 / 兄弟 / 陌生人 |

⚠️ **这是「减法错」，比「加法错」更难发现** ——
提示词看起来更精简了，反而像是精简纪律执行得好。
**「不要自己加戏」管的是加法，这条管的是减法 —— 两头都要防。**
| A3 动作 / 姿态 | 主体在做什么（静物也要写摆放关系）| ⭕ 建议 | 人物默认"自然地站着或坐着，身体朝向略微偏离镜头"；静物默认"居中平放" |
| **A3b 关系 / 视线** | ⭐ **画面里两个人以上时才存在**：身体的朝向和距离、眼睛看谁、谁实谁虚 | ⛔ **双人图必填且必问** | **⛔ 不许套默认值** —— 给 2~3 个具象候选让用户点（见下）|
| A4 服装 / 道具 | 穿什么、拿什么、有什么强身份道具 | ⭕ 建议 | 不写；写了就必须写材质和颜色 |

#### ⭐⭐ A3b 为什么单列一槽（双人像美感缺失的根因）

**「两个人并排站着、都看着镜头」= 影楼合影的构图语言。**
它是默认值里最危险的一个 —— 光打得再好，出来的也只是"曝光正确的合影"。

实测：连续几张双人图的姿态句**一字不差**，一直在换光、换介质、换场景、换画幅，
**唯独没动过人和人的关系**。这不是打光问题，是这个槽从来没被写过。

**双人像的美感来自三件事，一件都不在五官上：**

| | 写什么 | 判据 |
|---|---|---|
| **① 身体的关系** | 距离和朝向 —— 谁向谁靠、谁的身体朝着谁 | 有没有方向性，还是两个平行的人 |
| **② 视线的落点** | 眼睛看谁 —— **看镜头 = 摆拍，看对方 = 有戏** | 两条视线交叉了吗 |
| **③ 焦平面分层** | 两人不在同一景深，一实一虚 | 两块一样清楚 = 像贴在背景板上 |

⭐⭐ **「笑不自然」是同一个病根**：两个人都对着镜头笑 → **笑的对象是机器** → 必然摆拍。
**真笑的引子必须是旁边那个人，不是镜头。**

⛔ **关系动作属"剧情化设定"，不能擅加**（见 SKILL.md「不要自己加戏」）——
正确处理是**给 2~3 个具象候选让用户点**：

> 两个人的关系动作我按这几种来，你挑一个：
> **① 额头几乎碰在一起** —— 侧脸贴得很近，两个人都垂着眼，安静
> **② 一个在看对方、另一个在笑** —— 眼神有来有回，像刚说完一句话
> **③ 从背后环着，下巴搁在肩上** —— 身体叠在一起，脸朝同一边

⭐ 写法上要**同时把三件事写出来**，只写动作不够：

```
两个人的额头几乎碰在一起，身体向彼此倾斜、肩线交叠；
她垂着眼、嘴角有一点笑意，他的视线落在她的眼睫上（两个人都不看镜头）；
焦点落在她的睫毛上，他的肩线在焦外虚成一片。
```

⚠️ **单人图不需要 A3b**，但要顺带问一句"视线落点"（看镜头 / 看画外某个东西 / 垂下眼），
它决定了情绪走向 —— 给默认值"自然看向镜头"即可，不必升级成必问项。

### B 层 · 画面层

| 槽 | 回答什么 | 必填 | 缺省策略 |
|---|---|---|---|
| B1 媒介 / 渲染 | 这是照片、插画、3D、手绘、还是印刷品 | ✅ 必填 | 由画面类型推断，推断不出就问 —— 它决定后面所有槽的写法 |
| B2 风格 | 具体风格 / 参照系 / 艺术家 | ✅ 必填 | 用户没提就给 2-3 个候选让他挑（见 02） |
| B3 场景 / 环境 | 在哪、什么时间、什么天气、背景是什么 | ✅ 必填 | 按画面类型给一个"背景为深色纯色"或"虚化自然背景" |
| B4 光照 | 光源是什么、从哪个方向来、落在哪、阴影什么样 | ⭕ **强建议** | **永远不要留空** —— 见 03 第 1~3 步，AI 生图崩得最多的就是这一槽。<br>⛔ **两类例外：槽要"替换"而不是"填光位"** —— 技术图 → 均匀平光；绘画形式类 → 墨色的层次分布（见「特殊画面类型」一节）|
| B5 色彩 | 主色 + 补色（至少两个色温）| ⭕ 建议 | 从风格族继承；单色系风格除外（如黑白、单色调）。⚠️ ⛔ 不要默认"低饱和冷调" |
| **B5b 影调** | 高调 / 中间调 / 低调 —— 画面整体明暗 | ✅ 必填 | ⭐ **默认中间调**。⛔ 不要默认低调 / 暗调，见 `05` 的「影调」一节 |
| B6 构图 / 景别 | 拍到哪、机位在哪、用什么构图法 | ✅ 必填 | 由画面类型给默认景别；**画幅反向约束景别，这两个必须一起定** |
| B7 情绪 | 观感基调（宁静 / 压迫 / 孤独 / 热烈）| ⭕ 选填 | 不写；**写了就要落到可观察的东西上**，"氛围感"这种词零效果 |

### C 层 · 规格层

| 槽 | 回答什么 | 必填 | 缺省策略 |
|---|---|---|---|
| C1 画幅比例 | 1:1 / 3:4 / 16:9 / 9:16 … | ✅ 必填 | 先定"主体占画幅多大"，再按主体占比给（见下表）|
| C2 质量 / 细节 | 画质词、材质、细节层级 | ⭕ 选填 | 自然语言类模型**默认不堆画质词**（见 05）|
| C3 目标模型 / 语言 | 出给哪个模型、中文还是英文 | ✅ 必填 | 默认中文整段；用户点名 MJ/SD 才切形态（见 04）|
| C4 文字 / 标题 / 落款 | 画面里的标题、文案、手写落款 | ✅ 看用途 | **海报 / 封面 / 产品图 / 信息图 / KV → 主动问文字内容**；纯氛围图 → 默认不加 |

> ⭐ 影调槽只有 **B5b** 一个（在 B 层）—— 它是画面层的事，不在规格层重复设槽。

### 画幅按「主体占比」给，不按画面类型给

⛔ **画幅要跟主体大小绑，不是跟题材绑** —— 同一个"人物写真"，
人要占满画面和人在风景里，画幅完全不同：

| 主体占比 | 画幅 | 为什么 |
|---|---|---|
| 特写 / 面部占满 | 3:4 · 4:5 · 1:1 | 竖或方，让主体撑满 |
| 半身 / 中景 | 3:4 · 4:5 · 16:9 | 竖为主 |
| 环境人像（人偏小）| 16:9 | 横幅给环境留位置 |
| 纯风光 / 电影叙事 | 16:9 · 21:9 | ⛔ **21:9 只给明确的风光或电影感需求** |

⛔⛔ **21:9 不要当默认值** —— 它是宽银幕比例，天然把人物压小。
人物图给了 21:9，人就会变成两个小点（这是实战踩过的坑）。

## 二、画面类型路由（先定这个，再填槽）

**第一步永远是判断"这是张什么图"** —— 它一次性决定 B1/B6/C1 的默认值，
也决定后面该重点补哪几个槽。

| 画面类型 | 典型需求 | 重点槽位 | 默认景别 | 默认画幅 |
|---|---|---|---|---|
| **人物肖像 / 写真** | 人像、头像、写真、cos | ⛔ **先问人多大**；**双人则必问 A3b 动作骨架**；B4 光照 | 半身 | 3:4 / 4:5 |
| **⭐ 人物设定 / 角色设定** | 人物设定、角色设定、设定图、转面图、三视图 | ⛔ **默认出四视图**（左脸特写 + 正/侧/背），整套反写见「特殊画面类型 A」| 全身 | **16:9 横幅**（四格横排）|
| **角色立绘 / 卡面** | 单张立绘、概念设计、卡面、宣传立绘 | A2 / A4 / B2 / A3 | 全身 | 2:3 / 3:4 |
| **技术图 / 版式图** | 非人物的结构图、零件三视图、版式图、构图示意 | ⛔ **整套反写**，见「特殊画面类型 A」 | 全幅 | **3:2 横幅** |
| **场景 / 概念图** | 风景、世界观、大场景 | B3 / B4 / B6 | 远景或全景 | 16:9 / 21:9 |
| **产品 / 电商** | 产品图、卖点图、详情页 | A2 材质 / B4 / C1 | 中景或特写 | 1:1 / 4:5 |
| **海报 / KV** | 宣传海报、字体海报、主视觉 | B6 构图 / C1 / C4 | 中景 | 3:4 / 9:16 |
| **信息图 / 图表** | 数据可视化、流程图、科普图 | B6 版式 / C2 文字 | 全幅 | 3:4 / 16:9 |
| **UI / 界面图** | App 界面、网页截图质感 | B6 层级 / C2 | 全幅 | 16:9 / 9:16 |
| **品牌 / Logo** | 标志、辅助图形、周边 | A2 / B2 | 居中 | 1:1 |
| **建筑 / 空间** | 室内、外观、空间设计 | ⛔ **先问是哪一种**（五条岔路，见「特殊画面类型」）；B6 机位 | 广角 | 16:9 |
| **插画 / 绘本** | 儿童插画、杂志插图、故事图 | B1 / B2 | 中景 | 4:3 / 1:1 |
| **国风 / 东方** | 中国风、汉服、神话、节气 | B2 / A4 / B3 | 半身或全景 | 3:4 / 16:9 |
| **绘画形式 / 传统画种** | 水墨、工笔、版画、素描、油画 | ⛔ **光照槽要替换**，见「特殊画面类型」| 中景 | 自由 |
| **食品 / 生活方式** | 美食、咖啡、旅行记录 | B4 / B5 | 近景特写 | 4:5 / 1:1 |

⛔ **含人物的类型，第一件事永远是问「人在画面里多大」**（见 SKILL.md 起手第三步）——
它决定景别、画幅、光位，比题材本身更重要。
⭐ **唯一例外：「人物设定 / 角色设定」** —— 排布已把"人多大"定死（三格全身 + 一格脸），
**不要问，直接按四视图出**（见「特殊画面类型 A」）。
⛔ **画面里两个人以上时，第二件事是问「动作骨架」**（起手第四步）—— 它决定美感。

> ⚠️ 判断不出来时，**不要猜完就往下走** —— 用一句话把两个候选摊给用户：
> "你这张更像 A（人物写真）还是 B（场景氛围图）？这两个的默认构图和光位不一样。"

## 二之二、⛔⛔ 特殊画面类型：这几类要**整套反写**

**下面四类画面，本文件其余所有规则都要反着用。**
认出来就**整套切换**，不要一条条对抗 —— 那会写出自相矛盾的提示词。

| 类型 | 光照槽 | 构图六条 | 画幅 | 一致性靠什么 |
|---|---|---|---|---|
| **人物设定（默认四视图）** | **均匀平光** | ⛔ **全部作废** | **16:9 横幅**（四格横排）| 逐一钉死可辨识特征 |
| **技术图 / 版式图** | **均匀平光** | ⛔ **全部作废** | **横幅**（三格横排）| 逐一钉死可辨识特征 |
| **建筑 / 空间** | 正常（但要补机位和尺度）| ⚠️ 大部分天然满足 | 16:9 | —— |
| **绘画形式 / 传统画种** | **替换成「墨色的层次分布」** | ⚠️ 大部分作废 | 自由 | 锁墨色浓度 + 留白比例 |

### A · 人物设定：默认就是「四视图」

⭐⭐ **用户说「人物设定 / 角色设定」，除非他另有说明，默认按「四视图」出** ——
这是本 skill 的固定默认，不用问。

**「四视图」在这个 skill 里的定义（写死，避免歧义）：**

```
左起第一格 = 面部特写（只画头到肩）
右边三格   = 正视图 / 侧视图 / 背视图（全身立绘）
```

⛔ **不要理解成"四个角度的全身"** —— 那样会漏掉脸的特写，而脸恰恰是设定里最吃辨识度的部分。
⛔ **也不要理解成"三视图"** —— 三视图没有面部特写，是另一回事（用户明说"三视图"时才按三格出）。

⭐ **人物设定不需要问「人多大」** —— 四视图的排布已经把它定死了（三格全身 + 一格脸部特写）。
这是「人多大必须问」那条纪律的**唯一例外**，因为答案由排布本身给出。
这一轮该问的是**别的东西**：风格 / 服装细节 / 有没有参考图。

**标准写法（可直接照抄结构）：**

```
画幅：一张 16:9 的横幅图，画面横向等距分成四格，格与格之间留出很窄的浅灰间隔。

排布：左起第一格是这个角色头部到肩部的大特写，脸填满这一格、不画全身；
      右边三格依次是同一个角色的正面、侧面、背面全身立绘，
      三个立绘同样大小、站在同一条水平线上、间距相等。

背景：四格共用同一个浅灰色纯色背景，没有环境、没有道具、没有投影。

光照：均匀平光、四格的照度完全一致，没有明显的明暗分界和方向性阴影。

站姿：中性站立，双臂自然下垂、略微离开身体，双脚分开与肩同宽，
      三个视图用的是同一个站姿，脸分别朝前 / 朝侧 / 背对镜头。

一致：[逐条钉死] 发色 XX、发型 XX、瞳色 XX、上装 XX、下装 XX、腰带 XX、鞋 XX、配饰 XX、头身比 X 头身。

收尾：四格画的都是同一个角色，画面里没有其他人物，没有文字和水印。
```

⚠️ **收尾句要改**：普通图的 `画面里只有[主体]` 在这里会让模型以为"只能有一个人"，
**必须写成"四格是同一个角色"**，否则它可能把四格画成四个人。

⚠️ **要不要给这个角色一个称呼？** 要，但**要"带信息的称呼"，不要纯人名** ——
⛔ `苏晚` 这种纯人名在模型眼里信息量为零（「名词定律」的镜像问题：指代词和专名的语义都为零）。
✅ 用**带可画信息的短称呼**：`黑发女剑客` / `红披风少年` / `白色制服的军官` ——
它自带发色、服装、身份，后文可以反复复用，比每句重复一遍外貌省字。

#### ⛔ 四视图专属的五个坑

| 坑 | 症状 | 写法 |
|---|---|---|
| **特写格被画成全身** | 四格都是全身，脸小得看不清 | 必须明写「**第一格只画头到肩，不画全身**」—— 模型的默认先验是"四格都是立绘" |
| **背视图和正视图撞了** | 出来两个正面，或侧视图只是转了个角度 | 明写顺序和朝向：`正视图脸朝镜头 / 侧视图脸朝画面右侧 / 背视图完全背对镜头` |
| **背视图没东西可认** | 背面是一张空白的衣服背 | 背视图**看不到脸**，辨识度只能靠发型轮廓和服装背面 —— 要把`后领的高度 / 后背的剪裁 / 后摆的样式 / 发型从后看的轮廓`写具体 |
| **四格里出现了景深** | 后面的视图被虚化 | 明写「**四格都在同一焦平面，全部清晰，不要景深**」—— 技术图里景深是干扰 |
| **四格背景不一致** | 一格灰一格白，或某格冒出了环境 | 明写「**四格共用同一个纯色背景**」，⛔ 别只写"纯色背景" |

#### ⭐ 什么时候**不做**四视图（例外清单）

| 用户说的 | 按什么出 |
|---|---|
| 「单张立绘 / 卡面 / 宣传图 / 概念插画」| 走**角色立绘**（2:3 / 3:4 竖幅，要好看、可有氛围）|
| 「三视图」| 三格横排（正 / 侧 / 背），**不加面部特写** |
| 「五视图 / 加个 45° 视角 / 加背面细节图」| 按他说的格数排 |
| 「表情表 / 表情差分」| 那是另一类 —— 多格只画头，每格表情不同 |
| 「儿童绘本角色 / Q 版」要的是**插画**不是设定 | 走插画 / 绘本类型 |

**判据一句话：他要的是「读结构」还是「好看」？** 读结构 → 四视图；好看 → 立绘。

⚠️ **要不要在格下方标视图名（"正面""侧面""背面"）？**
**默认不标** —— 标签会挤占格子、还可能被画歪。用户要标就明写：
`每格下方居中一行很小的灰色字，分别是「正面」「侧面」「背面」`。

### A2 · 技术图 / 版式图（非人物）—— 整套反写

这类图的目的是**读结构**，不是好看。所有"好看"的手段在这里都是干扰。

| 本文件的常规规则 | 技术图实际要的 | 性质 |
|---|---|---|
| B4「光照永远不要留空」+ 打脸四件套 | **均匀平光**，不能有戏剧性明暗 | ⛔ **完全相反** |
| 构图六条（光源实体 / 两色温 / 真黑 / 发光介质 / 背景少而大有几何线）| 全部不适用，背景是**纯色板** | ⛔ **全部作废** |
| 「默认不要剪影」 | 不适用，本来就是看轮廓 | 不适用 |
| 画幅默认 2:3 / 3:4 竖 | 三格横排要**横幅 3:2 / 16:9** | ⚠️ **默认值给反了** |
| 装配顺序里的「场景」槽 | **整槽空缺**（背景是纯色）| ⚠️ 骨架缺槽 |
| 装配顺序里的「细节」槽 | 换成了**视图排布 + 站姿 + 多视图一致性** | ⛔ **缺槽** |

**替代写法（实测通过）：**

```
光照：均匀平光、没有明显的明暗分界和投影，三个视图的照度完全一致
背景：纯浅灰色纯色背景，没有环境、没有投影
画幅：一张 3:2 的横幅图，三个视图横向等距并排
一致性：三个视图是同一个人、同一套服装、同样的头身比；
       [逐一钉死] 发色 XX、发型 XX、瞳色 XX、外套 XX、腰带 XX、靴子 XX
```

⭐⭐ **一致性只能靠"把可辨识特征钉到具体细节"，不能靠"保持一致"这句话。**
「保持三个视图一致」是无效的 —— 模型不知道要一致什么。
**要逐条点名：发色 / 发型 / 瞳色 / 服装每个部件 / 配饰 / 头身比。**

⭐ **卡渲的「硬边阴影」和技术图的「均匀平光」不冲突** —— 它们在不同槽：
- **光位**写"均匀无方向性平光 + 只留很浅的结构阴影"
- **着色方式**写"阴影边界仍是硬边"
- **两句话放不同槽，不打架。**

⭐ **推论：需要读结构的技术图，卡渲比写实 3D 更适合** ——
写实渲染的次表面散射和皮肤纹理在技术图里全是噪声。

⚠️ **但"写实渲染 + 三视图 + 均匀平光"确实有张力**（这条仍未完全验证）：
平光 = 没有明暗层次 = 没有体积 = 皮肤看起来像塑料膜，而写实渲染的看点恰恰是"光打在皮肤上的反应"。
**可能的正解是「棚拍三点光 + 把补光开到接近 1:1 光比」**：
一盏柔光主灯（左前 45°）+ 大面积柔和补光 + 背景轮廓光 ——
阴影很浅、结构仍看得清，皮肤有正确体积。**遇到时按这个试，不要放弃写实。**

### B · 建筑 / 空间 —— **机位比建筑本身更重要**

⭐⭐ **建筑的「主体」不是那栋楼，是楼和周围的关系** —— 这是建筑类与人物 / 产品类最根本的差别。
同一栋房子，鸟瞰和人视角是**两张完全不同的图**。

⛔⛔ **建筑图的必问项里，机位排在建筑本身之前。**
⭐ **没有人做尺度参照，建筑会看起来像桌上的模型** —— 尺度参照也是必问项。

#### 五条互斥岔路，必须先问是哪一种

| 岔路 | 要什么 |
|---|---|
| **A 效果图** | 漂亮光线 + 尺度参照（人影）+ 玻璃里的灯 |
| **B 概念建筑** | 概念先行，允许不合理，重点在设计语言 |
| **C 实拍摄影** | 真实光线，可以歪、可以暗，不要完美 |
| **D 室内空间** | 人视角，家具和材质是主角，光从窗来 |
| **E 技术图纸** | ⛔ **同三视图整套反写**：均匀平光、不要氛围、不要色温对比 |

⛔ **不问这一句，默认值全错**（`01` 早期版本把建筑当成一行"广角 16:9"处理，覆盖不了这五条分叉）。

#### ⭐ 建筑类的一个便利：构图六条里五条是天然满足的

| 判据 | 建筑里对应什么 |
|---|---|
| 有亮面 | 立面被光打到的那个面 |
| 有一块真正的黑 | 悬挑结构的底面 |
| 有发光介质 | 玻璃幕墙里透出的室内灯 |
| 有一条几何线 | 山脊线 / 水岸线 / 建筑的边线 |
| 第二色温 | 天顶的深蓝 |

⭐ **建筑最大的便利是不用硬凑黑锚和介质 —— 它们本来就是建筑构件。**
**唯一要主动补的是两样：① 尺度参照（人影）② 光源实体入画**（比如贴着山脊线的低角度太阳盘）。

#### ⭐ 元素等价映射法（换建筑类型时用）

**换建筑类型 = 换整套材质描写，但不要推翻重写。**
找出旧版里每件元素在新建筑里的**对应物**，逐个替换 ——
比重新构思快，而且不丢已经通过的骨架。

| 旧（清水混凝土美术馆）| 新（江南民宿）| 功能 |
|---|---|---|
| 清水混凝土 + 木模板纹理 | 粉墙 + 风雨水渍痕 | 主材质 |
| 玻璃幕墙 + 室内透光 | 木格窗 + 窗棂里透出的暖黄灯 | 发光元件 |
| 悬挑底面 | 深黛色瓦垄压进暗部 | 黑锚 |
| 混凝土平台边线 | 青石板路 + 落进水里的水平线 | 几何线 |
| 贴山脊的太阳 | 贴屋脊线的太阳 | 光源实体 |

#### ⚠️ 两个建筑类特有的坑

**① 白墙是高危材质**（和玻璃同级）——
白色粉墙被暖色低角度光直射会**过曝成纯白**，一过曝就没有墙面纹理、整张图变贴纸感。
必须显式压住：`最亮的地方仍留着一层淡淡的灰、没有过曝成纯白`。

**②「不要人」是有代价的，必须主动交待** ——
人的功能是**尺度参照**；去掉之后建筑容易显得像桌上的模型。
专业空景效果图靠**物件**补尺度：船 / 竹丛 / 石灯笼 / 一双木屐 / 晾晒的衣物。
⚠️ **这是用户提的需求（不要人）引发的副作用，属必须主动提示的类型** ——
但**补什么物件要由用户点**，不要自己定。

### C · 绘画形式类（水墨 / 工笔 / 版画 / 素描）—— 光照槽要**替换**

⭐⭐ **这是 B4「光照永远不要留空」的第二次失效**（第一次是技术图 → 均匀平光）。

**绘画形式里"光源"根本不存在** —— 画面上没有打光这回事。
硬写光位会得到一张"被打了光的画"，两边都不像。

✅ **光照槽替换成「墨色的层次分布」**：

```
墨色从近景的焦墨推到远山的淡墨，最远的地方几乎融进纸色，
画面靠墨的浓淡分出前后，没有明确的光源方向
```

⭐ 五色分布：**焦 / 浓 / 重 / 淡 / 清** —— 从最黑的近景推到几乎融进纸色。

#### 水墨必须写三样（缺一样就退化成数码图）

1. **宣纸纤维纹理** —— 不写会出成数码图
2. **墨迹自然晕开的毛涩羽边** —— 不写会出成矢量图
3. **干笔飞白露出纸色** —— 不写会出成平涂

#### ⭐ 一枚朱红印章 = 「唯一高饱和色」的传统解法

纯墨画容易显平，一枚朱红印章是几百年的老办法。
⚠️ **但模型写中文印文必出错字** → **只写印章形态、不指定文字内容**，
交付时提醒用户后期贴。**题字同理。**

#### 组图一致性：锁什么，变什么

| 锁死（决定"一个手笔"）| 拉开（决定"不是同一张"）|
|---|---|
| **墨色浓度 + 留白比例** | **题材 + 构图** |

⛔ 不要靠"换颜色"拉开 —— 水墨组图一换色就不是一个手笔了。

## 三、每槽的提问模板

提问的硬规则在 SKILL.md 里（每轮 ≤3-4 项、每项必须带默认值、不重复问）。
这里是**每槽问的时候具体怎么开口**。

| 槽 | 问法（带默认建议） |
|---|---|
| A1 主体 | "主体就按你说的「___」来，对吧？还是想换成 ___？" |
| A3 动作 | "我给她设计成「___」，这样比站着更能撑住画面，OK 吗？" |
| **A3b 关系 / 视线**（双人）| ⛔ **不给单一默认值**。给 2~3 个候选让他点：<br>"两个人的关系动作我按这几种来，你挑一个 —— ① 额头几乎碰在一起 ② 一个在看对方、另一个在笑 ③ 从背后环着、下巴搁在肩上" |
| A4 服装 | "穿搭我先定「___」——要改风格（比如换成中式 / 未来感）随时说。" |
| B1 媒介 | "出成**照片质感**还是**插画**？这两个出来的完全不是一种东西。" |
| B2 风格 | 给 2-3 个候选，每个一句话说清"出来会是什么样"（不说术语）|
| B4 光照 | "光我打算这么打：___（光源 + 方向 + 落在哪）。要换方向吗？" |
| B5 色彩 | "整体色调走「___ + ___」，冷的那半用来提亮画面。" |
| B6 构图 | "画幅我定 ___，机位 ___ —— 这两个绑在一起，改一个另一个也要动。" |
| C1 画幅 | "你是发___（平台）对吧？那我按 ___ 出。" |

**反例（不要这么问）**：
- ❌ "请问你想要什么风格？" —— 开放式问题，用户答不出来，等于把活推回去
- ❌ "光照、色彩、构图、情绪分别要什么样的？" —— 一次四个开放式问题，用户会跑
- ❌ "你确定要 16:9 吗？" —— 除非命中红线，不要问确认题

## 四、装配顺序（怎么写成一整段）

自然语言类模型吃**整段句**，顺序不是随便排的 —— **前面的句子会盖过后面的**。
顺序依据 OpenAI 官方给图像模型的推荐读法：**意图 → 场景/背景 → 主体 → 关键细节 → 文字 → 约束**。

按下面的顺序拼，每一条都是一个有主谓的句子，不要写成逗号分隔的词组。

```
① 意图 / 用途     —— 第一句就说这是什么图、干什么用
② 画幅 + 景别     —— 多比、拍到哪、主体占画幅多大
③ 场景 + 光源位置 —— 在哪、什么时间、光源是什么、架在哪（光源写在场景句里）
④ 主体 + 关系     —— 是谁/是什么，关键特征，在做什么，穿什么；
                    ⭐ 画面里两个人以上时，**关系动作 + 视线落点 + 焦平面**写在这里
⑤ 光的落点        —— 光打在主体上落在哪，明暗怎么分
⑥ 色彩 + 材质     —— 主色 + 第二色温在哪；材质与微纹理
⑦ 文字（可选）    —— 手写落款 / 标题的位置和形态
⑧ 收尾            —— 一句「输出规格」约束（主体数量 + 文字水印），2~3 项
                    ⛔ 不写身体部位的质量要求（如"双手五指完整"），
                    那会凭空造出一双手 —— 见 `04` 的「收尾句不要写身体部位的质量要求」
```

⛔ **特殊画面类型要改骨架本身**（见上一节）：
- **技术图**：没有"场景槽"（背景是纯色），补一个"视图排布 + 一致性"槽
- **绘画形式类**：没有"光源"，第 ③⑤ 位的"光"合并成"墨色层次分布"

### 四条顺序规则

- ⛔⛔ **第一句必须写"这是什么图"，不能直接写主体。**
  ✅ `为自媒体封面做的一张 3:4 竖幅人像照片` ／ `一张电影感的双人特写照片`
  ⛔ `一个年轻女性……`
  开头的词会**选中模型的"模式"** —— 这是提升最大的单点改动。
- ⛔ **场景写在主体之前。** 官方推荐先把"这是在哪、背景是什么"交代清楚，再放主体。
  实测主体和场景互换影响相对小，但**意图打头 + 场景先于主体**是官方顺序。
- ⛔ **光源位置写在场景句里**，不要单独起一句写"光照"。
  光是靠场景写出来的，不是靠形容词 ——
  "身后是敞开的店门和门外的街道"能出逆光，"身后是干净的墙面"出不来（墙把光源挡在画框外了）。
- ⛔ **画幅和景别必须相邻**：它们互相约束，隔开写会得到自相矛盾的组合。

### 装配示例

> 输入碎片：`赛博朋克女孩，雨夜`

```
一张 9:16 的竖幅电影感人像照片，从腰往上入镜。        ← ① 意图 + ② 画幅景别

一条狭窄的雨夜巷道，两侧是密排的霓虹招牌和自动贩卖机，  ← ③ 场景 + 光源位置
路面是湿润的沥青、积着水洼，远处收进深青色的街景；
一台自动贩卖机的冷白灯箱就在她正前方偏下的位置。

一个年轻女性站在画面中心偏右，黑色短发被雨打湿贴在脸侧， ← ④ 主体
穿一件表面有反光的深色连帽夹克，正微微抬头看向镜头。

灯箱的冷白光从下往上打亮她的下颌和鼻梁，              ← ⑤ 光的落点
鼻侧留下一小块亮斑，另外半张脸落在柔和的暗部里；
右后方一块暖橘色霓虹灯牌在头发外缘勾出一条暖色亮边。

画面整体是青蓝冷调，唯一的暖色是那块霓虹灯牌和地面的倒影。 ← ⑥ 色彩 + 材质
雨丝在空气里被灯光照成一条条亮线，湿润的路面把霓虹拉成长长的反光带。

画面里只有她一个人，没有文字和水印。                    ← ⑧ 收尾
```

对照槽位：① 意图 ✅ / ② 画幅景别 ✅ / ③ 场景+光源 ✅ / ④ 主体 ✅ / ⑤ 光落点 ✅ /
⑥ 色彩材质 ✅ / ⑧ 收尾 ✅（⑦ 文字没要，跳过）。
注意没有任何一个槽是靠堆形容词完成的 —— 每个槽都写成了**具体的东西**。

## 五、缺省值总表（用户不回答时直接填）

⛔ **说明：这张表是"实在问不出来"时的兜底**，不是"不用问"的借口。
有具体人物的图，**"人多大"必须先问**（SKILL.md 起手第三步），不要直接查这张表。

| 场景 | 缺省 |
|---|---|
| **没说人多大**（人物图）| ⛔ **这一项不许查表，必须问**。实在问不出来 → 半身、两人占画面中段、能看清脸 |
| **没说关系动作**（双人以上）| ⛔ **这一项不许查表，必须问** —— 给 2~3 个具象候选让他点。<br>⛔ **绝不默认"并肩站着、都看镜头"** —— 那是影楼合影的语言 |
| 没说主体多大（非人物）| 产品 → 中景；场景 → 全景 |
| 没说画幅 | 按主体占比给（见上）：特写 3:4 · 半身 3:4 · 环境人像 16:9。⛔ 不要默认 21:9 |
| **人物设定没说格数** | ⭐ **默认四视图**（左脸特写 + 正 / 侧 / 背），16:9 横幅 —— **不用问，直接按这个出** |
