# 03 · 光照与构图判据

AI 生图崩得最多的不是风格，是**光和构图**。
风格错了重出一张就行；光和构图错了，改十版措辞也不会动 —— 因为卡的是结构。

本文件是**判断流程**，不是词表。每一步只做一个决定，每个决定有判据；
判不出来就停在那一步，别往下走，也别改措辞去撞。

📌 **步骤号是稳定编号**（本文件的「第 X 步」是全局接口，其它文件按步骤号引用它）：
- 新增步骤一律插 `x.5`（如「第 2.5 步」），⛔ **不重排已有编号** —— 外部引用才不会失效
- ⚠️ 其它文件之间互相引用时**按标题引用，不按节号**（节号会因插入新章节而错位）

## 第 0 步：画幅与景别必须一起定

**这两个是绑定的，改一个另一个必须跟着改。** 这是全流程最容易翻车的一处。

| 景别 | 拍到哪 | 能用的画幅 |
|---|---|---|
| 特写 | 领口以上 | ⛔ **只能竖幅**。16:9 里做不出特写 |
| 近景 | 胸口以上 | 竖幅 / 横幅都行 |
| 半身 | 腰以上 | 竖幅 / 横幅都行 |
| 中景 / 全身 | 腿、鞋、地面 | 优先横幅 |
| 环境人像 / 场景 | 人小、景大 | ⛔ **只能横幅** |

⛔ **16:9 的画框本身在要求横向填充** —— 你让人只占半边，模型会把另一半补成环境，
人越补越小。要特写就换竖幅，别在 16:9 里磨措辞。

⛔⛔ **21:9 只给纯风光 / 明确的电影感需求，不要当默认值。**
它是宽银幕比例，**天然把人压小** —— 人物图给了 21:9，两个人会变成画面里的两个小点。
人物特写和半身图，画幅用 3:4 / 4:5 / 1:1。

⭐ **画幅跟「主体占比」走，不跟题材走。** 同一个"写真"：
脸占满 → 3:4；半身 → 3:4；人在风景里 → 16:9。

⭐ **字数也是控景别的主变量，而且比相机句更强**：
**写了哪个部位，就等于把画框拉到哪个部位。**
- 中景里写"裙摆垂到小腿" → 画框滑成全身
- 特写里写"她穿着开衫" → 立刻退回胸像
- 想"脸大 + 服装完整" → 用**半身档**（有完整上装、不写腿），不要用最近的景别档

⛔ 写完逐条查一遍：**我提到的每个身体部位 / 服装件，在不在这个景别的画框里？**
不在的会被模型自己编出来。

## 第 1 步：先定光位（打脸光 还是 镶边光）

**这一问必须先答。答错了，后面每一步都做对也是废片。**

| 你要的 | 主光位置 | 画面会是 |
|---|---|---|
| 轮廓光 / 发丝光 / 剪影 / 氛围 | 正后方 / 侧后方 | ⚠️ 主体只剩环境光 —— **必须另外补一个照到正面的光源** |
| 主体要好看（人物要美就选这个）| 见第 2 步的两种写法 | 一块**明确的亮面** + 一块暗面 |

⛔⛔ **例外：两类画面不走这一步**（见 `01` 的「特殊画面类型」一节）：

| 类型 | 光照槽怎么处理 |
|---|---|
| **人物设定**（默认四视图）| 反写成**均匀平光**，四格照度完全一致 —— "打脸"和"镶边"都不适用 |
| **技术图**（三视图 / 版式图）| 反写成**均匀平光**，"打脸"和"镶边"都不适用 |
| **绘画形式类**（水墨 / 工笔 / 版画 / 素描）| **光源根本不存在** → 替换成「墨色的层次分布」（焦浓重淡清）|

### ⛔⛔ 剪影的代价：它会把「人的美」换成「风景的美」

**剪影不是"光的强弱"问题，是画面类型问题。** 人物一旦变成纯黑轮廓，
观众能看到的信息只剩下：**姿态和关系** —— 表情、眼神、皮肤、年龄、情绪全部消失。

| 剪影成立的条件 | 剪影不成立的条件 |
|---|---|
| 用户明说"剪影 / 背影 / 不要露脸" | 用户给了任何具体情绪词（温柔 / 亲密 / 幸福 / 忧郁）|
| 主体是姿态本身就有信息的东西（舞者、跳跃、动作） | 主体是两个人的关系（恋人 / 亲子）—— 关系靠脸传 |
| 配"极简 + 强几何"的构图目标 | 配"朦胧 / 唯美 / 氛围"这类感受词 |

⭐ **判据一句话：这张图如果人变成纯黑剪影，用户还认得出这是他想要的吗？**
认不出 → **不要剪影**，改用侧前光或正前偏下的打脸光。

⚠️ 同理，**"背对镜头 / 望向远方 / 不看镜头"是三个独立的、会削弱情绪的动作**。
它们和剪影一样，都只能由用户主动提出，不能由你补默认值。
默认应该是"**能看见脸**"。

### ⭐ 剪影成立时：打脸四件套要整套换掉

**剪影模式下"打脸四件套"不适用** —— 照抄会自相矛盾（既要亮面又要剪影）。
正确写法是**三件**：

1. **轮廓边光（发丝亮线）** —— 一整圈细细的亮线勾住头肩轮廓
2. **光从两个人身体之间漏出来** —— ⭐ 这条最有戏，一眼读出"两个人"的关系
3. **主体本身当黑锚** —— 剪影就是画面里最黑的东西，**不用再加黑锚**

⭐ 第 2 条是双人剪影的专属解法：**光从两人之间的缝里漏过来**，
比"两团黑影并肩站着"多出一整个层次。

⛔⛔ **"光对了 ≠ 好看。"** 一组实拍里八张的边光和补色全部成立、挑不出一处光学错误，
但主光全在主体后方 —— 正面只剩均匀环境光，没有立体感，**八张全毙**。

⭐ **要主体好看，必须把亮面和暗面都写出来。** 写"柔和地照亮她的脸" = 均匀光 = 等于没打。
通用公式（人物版，其他主体换名词）：

```
把她的额头、颧骨和鼻梁照得发亮，鼻子侧面下方留下一小块三角形的亮斑，
另外半张脸整个落在柔和的暗部里；睫毛在被照亮那半边的脸颊上投下细影
```

⛔ 第三件（暗面）**必须和前两件一起出现**。只写"脸落在柔和的暗部里"而不写亮面，
就是全暗脸 —— 这一档废过 38 张。

⛔⛔ **这个明暗结构不许为了"提亮画面"而被抹掉。**
治"太暗"要在**整体曝光**和**暗部亮度**上改（暗部从黑改成浅灰），
**不是**换成 `大面积散射光 / 均匀柔光` —— 那会让脸变平，**亮度上去了、人不美了**。
详见 `05` 的「亮和美是两个独立的轴」一节。
⛔ 也不要**另外再单写一句**"脸的其余部分落在暗部里"，那不是加分，是重复。

## 第 2 步：选光源，并钉死三个维度

**先问"这个场景在这个时刻，什么东西是亮的"：**

| 场景 | 主光源 |
|---|---|
| 日出 / 日落户外 | 太阳（低角度，天然落在头肩高度，最省事）|
| 正午户外 | ⚠️ 没有低位光源 → 改时间，或退回第 0 步换景别 |
| 夜晚有光源（街 / 舞台 / 庭院）| 场景自带的：霓虹 / 灯笼 / 灯箱 / 火盆 / 射灯 / 自动贩卖机 |
| 夜晚无光源（山顶 / 荒野 / 湖边）| ⛔ 必须自带一个：营灯 / 提灯 / 篝火 / 手里的发光物 |
| 室内 | 窗 / 门缝 / 矮处的灯具 |
| 棚拍 | 柔光箱（写在主体侧前 45°，不要写在正前方）|

**再钉三个维度，缺一个就飘：**

### ① 距离 —— 光源离主体能不能到半米~两米
"整片城市霓虹就在她身后"（几百米外）= 零轮廓光，出来是好看的背景板。
**到不了这个距离 → 换光源，别改措辞。**

### ② 方位 —— 高度和方位要**一起写**
⛔⛔ **不要写"光源在正前方、和主体的脸一样高"** —— 那个位置正好是**镜头的位置**。
模型不肯让光源挡住镜头，一律把它挪到主体身后或头顶去。于是本想要的正面主光变成真逆光：
正面一点直射光都没有，亮面 / 三角亮斑 / 睫毛投影全都得瞎编，**脸崩**。

⭐ **只有两种写法验得住**，共同点是**物理上没法被挪到背后**：

| 写法 | 为什么挪不走 | 例句 |
|---|---|---|
| **侧前方 45°** | "左前方 45 度"是**方位角**，无歧义 | `太阳在她左前方 45 度的树梢上压得很低，正斜劈在她脸上` |
| **正前偏下** | "比她的脸低一截 / 低半米"是**高度差**，无歧义 | `一盏暖橘的灯箱在她正前方、比她的脸低半米的地方直直照上来` |

⭐ 判据一句话：**写方位角或高度差，别写"和脸一样高"。**

⚠️ **"和她的头一样高"这句只能用在逆光（正后方）上**，绝不能用在主光上。用在逆光上是对的：
`光源在她正后方、和她的头一样高，整个头的外圈镶上一整圈细细的暖色发丝亮线`。

### ③ 支架 —— 光源要架到主体高度，靠场景里一个东西托住
⛔ **判据三条，缺一条等于没有支架：有一道缝 / 比主体高 / 离主体两米内。**

| 场景类型 | 支架 |
|---|---|
| 自然 | 两棵树干之间 / 一棵孤树分开的两根主枝之间 / 岩石 / 断墙 |
| 城市 | 两栋楼的缝 / 巷口 / 门洞 / 桥洞 / 棚架立柱 |
| 室内 | 门框 / 两扇门之间 / 书架之间的窄缝 |
| 人造 | 花架立柱 / 牌坊 / 晾晒的床单之间 / 舞台桁架 |

- ⛔ **没有缝的三种直接换地点**：开阔天空、光秃秃的海平线、身后一整面墙 / 门 / 一排橱窗
- ⛔ **比她高** —— 齐胸高的花穗、芦苇、麦浪**不是支架**。
  原因：开阔地里太阳的高度由地平线决定，形容词压不过地平线。
  要抬到头肩高度，必须给一个**比她高、并且在画面里画出来的实体**
- ⛔ **离她两米内** —— "太阳卡在她身后两座石雕之间"，石雕在几十米外 → 太阳没进画，一条边光都没有

## 第 2.5 步 · ⭐ 天然反光板 —— 补光的最省字解法

**问题场景**：两个人并肩面向镜头 + 单一侧光（侧前 45°）→
**一个人满脸亮、另一个人脸发黑**。这是双人打脸光最容易翻的车。

**解法**：**让场景里本来就有的东西当补光板**，不要去加第二个光源。

> `街道另一侧的白墙被太阳照到，把光反照回两人落在暗部的那半边脸上`

⭐ **物理上真的**（白墙朝街心，太阳从左来正好打它），而且**不引入任何新物体** ——
所以它同时满足"不要自己加戏"这条纪律。

### 可用的天然反光板

| 环境 | 反光板 |
|---|---|
| 城市 / 街 | 白墙 / 浅色铺装 / **大玻璃幕墙** |
| 水边 | 水面 / 沙滩 |
| 雪地 | ⭐ **积雪本身就是超大反光板** |
| 室内 | 白墙 / 浅色地板 / 浅色桌面 |

⭐ **三个好处，一个都别漏**：
1. **比另加一个光源省字** —— 不用再描述第二盏灯的位置和性质
2. **更可信** —— 场景里真有的东西，模型不会画崩
3. **顺带满足「两个色温」** —— 反光板带的是**环境色**（白墙带暖、水面带冷）

⚠️ **一定要写"它被光照到"** —— 不写的话模型会把那片墙画成暗的，
一点光都反不回来。

## 第 3 步：写场景句 —— 光是靠场景写出来的，不是靠形容词

**全流程最贵的一条。** 把场景写成物理上只可能这么打光，而不是形容光。

```
场景句 = 时间地点 + 光源在哪（第 2 步的三个维度）+ 背景被照透 + 天空长什么样
```

> `黄昏的老街，一盏很大的红灯笼就挂在她正后方半米、与她的头同高、正对着镜头，
> 右边三分之二是向远处收进去的整条青石板老街，木格窗被照成发亮的暖橙色，
> 天空是刚暗下来的深蓝色`

三条硬要求：

1. ⛔ 背景要写**"被这个光源从背后照透成发亮的暖金色"**；
   ⛔ **不能写"身后是逆着光的树丛"** —— 会被画成实体暗块，一个光斑都不出。
2. ⛔ **时间词不交代天空长什么样**。只写"日出的白花田"出来是大白天。
   要把天空画出来：`太阳只露出一半、天边是浓的橘红色、天顶还是没褪干净的深蓝色`。
3. ⛔ **背景的详略跟着景别走**：小景别（特写 / 近景）写死"糊成一片没有细节"；
   大景别（半身 / 环境图）**反过来要有细节**，并且收尾句里的"浅景深"要摘掉。

---

## 第 4 步：加一句空气介质

**没有介质，光就只是背景亮，不成氛围。**
跟着场景选一样：细尘 / 飞絮 / 花瓣 / 水雾 / 雪粒 / 火星 / 干冰烟 / 细雨丝 / 晨雾。

> `空气里浮着被照亮的细尘`

⚠️ **介质要吃画幅**：特写里够用的细尘、萤火，放进横幅就撑不起 2/3 的风景，
整张会发闷发空 —— 要换成整片的花穗 / 落叶 / 雪 / 火星 / 水光柱。

## 第 5 步：配第二色温 —— 补色对

**光已经对了但画面还是平、不抓眼，九成是因为整张图只有一个色温。**

⛔⛔ **但先确认影调（明暗），再配色温。** 这是两件事：
- **影调**：画面整体是亮的还是暗的（高调 / 中间调 / 低调）—— 见 `05` 的「影调」一节
- **色温**：画面有几个冷暖色 —— 本节

⛔ **最常见的错误是把"冷调 + 低饱和"当成默认** —— 那是一套完整的**暗调配方**，
不经确认就给，出来的图必暗。用户说"朦胧 / 氛围"要的是**空气感**，不是**暗**。

| 主光是暖的 | 冷的那一半去哪找 |
|---|---|
| 暖金落日 / 日出 | 天顶还没褪的深蓝、远山的冷蓝剪影、雾蓝色的衣服 |
| 暖橘灯（灯笼 / 钠灯 / 马灯 / 橱窗灯箱）| 刚暗下来的暮蓝天、冷蓝的雪夜、深青蓝的街 |
| 火橘 / 熔岩 | 深蓝紫的夜空、远处冷灰的山影 |

| 主光是冷的 | 光源实体可以是 | 暖的那一半去哪找 |
|---|---|---|
| 青蓝霓虹 / 屏光 | 霓虹招牌 / 自动贩卖机 / 一列机柜指示灯 / 显示器 | 侧后方一块暖橘灯牌、一扇暖黄窗、一枚暖橘电源灯 |
| 蓝紫射灯 | 舞台射灯 / 投影 / 顶排灯 | 台下一片暖橘荧光棒、过道的暖橘引导灯带 |
| 冷蓝月光 / 雪地 / 冰面 | 月亮 / 雪后未升高的天光 / 透光的冰壁 | 远处一扇暖黄窗、场边一盏没关的暖橘灯、地平线一线暖橘暮色 |

一句话记法：**主光暖的，去天空和远景找冷的；主光冷的，在近处塞一个暖光源。**

⛔ **不许单独写"暗部是冷的"** —— 模型会把整张图一起吹冷。
冷暖分离只能靠**场景自带两个色温的光源**。

⚠️ 除了"有没有"，还要看**够不够**：冷的那一半要**占得到 1/4 画幅**、是**饱和色**。
一整片饱和紫的花架 ✅；一条淡蓝棉布裙 ❌（整张仍会读成全暖）。

## 双人图 / 多人图 · 四个专属问题

单人的所有规则都成立，但画面里超过一个人时，有四个额外会翻车的地方。

### ① 焦平面必须分层（一实一虚）

两个人站在同一个焦平面上 = **两块一样清楚 = 像贴在背景板上** ——
这是半身双人图最常见的失败。

✅ 写法：`焦点落在她的睫毛上，他身后的肩线在焦外虚成一片`

⭐ **双人图的"前后关系"是靠焦平面读出来的，不是靠站位描述。**
写"两个人一前一后站着"没用 —— 要写**谁在焦内、谁在焦外**。

### ② 单一侧光会让一个人脸黑

两个并肩面向镜头的人 + 单一侧光（侧前 45°）→ 一个人满脸亮、另一个脸发黑。
**解法见上一节的「天然反光板」** —— 用场景里的大面反射体补光，不要加第二个光源。

### ③ 伪自拍：一整套独立的固定装置

用户说"**自拍 / 合影感 / 手机拍的 / 随手拍**"时，走的不是普通构图，
是一套**固定的机位关系**：

| 要素 | 写法 |
|---|---|
| 相机位置 | 举在两人面前**一臂距离**、**比眼略高** |
| 镜头 | **轻微广角**（近距离的透视拉伸）|
| 人物 | **两个人挤在镜头前**，靠得很近 |
| 背景 | 被推远、**收成一条透视走廊** |

⛔ **它和平视半身双人是两种不同的图** —— 不要用普通双人构图的方法去写伪自拍。
⭐ 伪自拍的好处是**它自带了"关系"**（两个人挤在一起看同一个镜头，这本身就是关系）。

### ④ 宽幅 + 双人 = 结构性矛盾

**16:9 / 21:9 里放两个人 → 脸必然小于画幅的 1/5。**

⛔ **解法不是磨措辞，是提前把岔路摊给用户：**

> 这个画幅下两个人有两种做法：
> **① 做成剪影** —— 本来就不看脸，宽幅反而合适，靠姿态和关系读
> **② 换竖幅 / 方形** —— 才能看清两张脸
>
> 你要哪种？

⭐ **判据同「剪影的代价」**：这张图是靠**脸**还是靠**姿态**。
靠脸 → 换画幅；靠姿态 → 剪影成立，按剪影的三件套写。

## 构图六条（决定"好不好看"，和光无关）

⛔ **光全对了也可能整张不好看。** 这六条是独立的一关。

### ① 背景要"少而大"，并且带一条干净的几何线
⭐ 这条是**唯一能 100% 分开"选中"和"被毙"的判据**，先查它。

| | 被选中的 | 被毙的 |
|---|---|---|
| 背景 | 海+天 / 一整面暗墙 / 暮蓝天 / 雪街 —— **元素少、块面大** | 夜市摊档 / 一堆糊光斑 / 观众席人头 / 一片碎树干 |
| 几何线 | 窗棂格 / 海面反光带 / 长弧顶棚 / 花架长廊 / 桥架透视 / 梯田曲线 | **一条都没有** |

⛔ **细碎堆叠的背景，虚化解决不了** —— 摊档、人群、一堆散落光斑，糊了照样把画面搅浑。
它们提供的是"信息量"不是"结构"。

⚠️ **"背景比主体暗"不能代替信息层级** —— 暗背景照样可能因为高锐度、高微反差、
密集高光而显得繁杂。分层要四级，写提示词时逐级点名：
**主体清晰区 → 主导大形 → 次级细节 → 连续低细节区（留白）**。

⭐ 两条修法，二选一或都要：
- 给一条**贯穿画面的线**：透视走廊（花架 / 樱花隧道 / 街道 / 车厢）、水面反光带、栏杆、窗棂、一排灯、山脊、地平线
- 把背景**换成一两块大东西**：海 + 天 / 雪坡 + 天 / 一整面墙 / 一整片暮色

### ② 光源实体要入画
太阳盘 / 一排灯泡 / 一扇窗 / 一堆篝火 / 一盏灯笼 —— **把那个东西本身画出来**，
让人看得见光是从哪来的。

### ③ 要有一大片"被主光照透、自己变成光源"的介质，占画幅 ≥ 1/3

| ⛔ 不算 | 为什么 |
|---|---|
| 松针 / 藤蔓叶 / 砖墙 / 铁架 | 不透光，背光时是实体暗块 |
| 城市霓虹 / 窗灯 / 银河 / 远处的云海 | 亮，但在几百米外，且不可能被"照透" |

可透光清单：花穗 / 花瓣 / 落叶 / 芒草穗 / 蒲公英绒毛 / 雪帘 / 雨丝 / 火星 / 水花 / 雾里的光柱 / 薄纱。

### ④ ⚠️ 有一块真正的黑 —— 这是**条件判据**，不是每张都要

⛔⛔ **不要每张都加黑锚 —— 它会整体压低画面亮度。**
这条的原始用途是治「**全是柔灰中间调 → 发闷、不抓眼**」，
**只在画面已经发灰发闷、缺对比时才用**（见 `06` 的"偏灰发闷"症状）。

| 该加黑锚 | ⛔ 不该加 |
|---|---|
| 画面灰扑扑、像蒙了一层 | 高调 / 明亮 / 通透的图（会毁掉轻快感）|
| 需要"重"和"戏剧性"的情绪图 | 日系 / 清爽 / 护肤 / 白底产品图 |
| 低调 / 电影感 / 情绪向 | 已经有大面积暗部的图（再加就全黑了）|

⭐ 加分的时候记住：**黑锚要挂在场景里，不能指望主体的衣服** ——
服装由角色设定决定，不受场景句控制（写好的黑制服出成白裙，黑锚当场消失）。
挂场景的：树干 / 立柱 / 屋瓦 / 山脊剪影 / 湿黑路面 / 车厢暗部。

⚠️ **默认不加。** 用户说"朦胧 / 氛围"不等于要黑锚 —— 那类词要的是"空气感"，不是"重"。

### ⑤ 主体必须够大
主体占画幅太小 → 撑不住画面。人物的判据：**脸占画幅 < 1/5 → 换景别或换画幅。**

### ⑥ 服装/道具是画面元素，不是背景板
一组十张里连出四张"白针织衫 + 牛仔裤"，光再对也只是随手拍。
判据：一组里**有没有重复穿同一件**；单张看**这身衣服有没有颜色和廓形**。

## 组图：一次要出多张时，怎么不"一个味"

单张都成立，十张摆一起像同一张 —— 这是模板化。沿**六个轴**拉开，缺一个就还是一个味道：

| 轴 | 怎么算拉开了 | 怎么数 |
|---|---|---|
| **景别** | 特写 / 近景 / 半身 / 中景轮着来 | 各占多少 |
| **光位** | 侧前 45° / 正前偏下 / 侧后 / 正后 / 自下而上 | 各占多少 |
| **场地类型** | 室内 / 海 / 街 / 雪原 / 山野 / 花树 / 工业…不重样 | 有没有重的 |
| **主光色温** | 全组同一个色温 = 一个味道 | 冷主光张数 / 总数，**< 1/4 就是病** |
| **动作骨架** | 每张的身体支撑点、手部任务、表情都不同；**双人组还要换"关系"**（谁靠谁 / 看谁 / 谁实谁虚）| 把动作那句抄出来去重，**重复率 > 1/3 就是病** |
| **机位** | 平视 / 俯拍 / 低机位 / 门框窥视 / 缝隙视角 | 全是平视 = 病 |

⛔⛔ **后两个轴是同质化最直接的来源，而且最好查** —— 它们能脚本化去重，
把 `动作` 和 `机位` 两个字段丢进 `set()` 比长度就行，比其余四个轴都硬。
实拍：一批 12 条里动作有 10 条是同一句、机位 12 条全平视，那批只挑中 1/12。

⛔⛔ **最容易用错本文件的方式：把每一条都套在每一张上。**
实测：全套骨架无差别套用的两批各只挑中 1/12；改成**每条先定一个"成立点"、其余允许留白**
的那批是 6/12。**一套骨架只能撑一批** —— 第二批要么换成立点，要么换轴
（画幅 / 色温 / 成像系统），**光换穿搭和场景不够**。

⭐ **"成立点"= 这张图靠什么撑住**，一两个词，写在动笔之前：

| 成立点 | 靠什么撑住 | 例子 |
|---|---|---|
| 场景 + 镜头 | 一个有说服力的地方 + 一个不寻常的机位 | 昆虫视角从花丛缝隙里看她 |
| 光线 + 妆面 | 一种光打在一张脸上，别的都让位 | 午后窗光 + 柔雾 + 奶油裸妆 |
| 场景关系 + 成像方式 | 主体和这个地方的关系 + 一种记录方式 | 夜间办公室白板 + 直闪 |
| 道具 + 光线 | 一件强身份道具 + 一束窄光 | 暗调琴房 + 大提琴 |
| 成像方式 + 场景 | 一种质感统治全画面 | 热带旅馆走廊 + VHS 过曝 |

### 绘画形式类的组图：锁什么、变什么

| 锁死（决定"一个手笔"）| 拉开（决定"不是同一张"）|
|---|---|
| **墨色浓度 + 留白比例** | **题材 + 构图** |

⛔ 水墨组图**不要靠换颜色拉开** —— 一换色就不是一个手笔了。
这条规则和上面六个轴**不通用**：绘画形式类优先保"同一个人的手"，不是保"每张不一样"。

## ⭐ 一条定律：名词自带的语义，压得过任何形容词

这是本文件里**唯一能预测新坑**的东西。五个独立实例的共同解释：

> **模型先按名词的常识把东西放好，再去读你的形容词。
> 形容词只能微调，推不动名词自带的位置 / 高度 / 数量 / 时间 / 属性。**

| 名词带进来的 | 症状 | ⛔ 压不住的写法 | ✅ 解法 |
|---|---|---|---|
| **高度**（灯具装在哪）| 顶光，脸压平 | "路灯，灯头和她的头一样高" | ① 换**本来就矮**的灯具：矮墙上的马灯 / 台灯 / 灯笼 / 帐篷杆上的营灯<br>② ⭐ **用户点名不能换灯时 → 改"光的性质"**（见下）|
| **高度**（招牌装在楼上）| 光源被画到二楼外墙 | "霓虹灯箱招牌，比她高出一头" | 换**天生齐人高的面光源**：自动贩卖机 / 橱窗灯箱 |
| **数量与排布**（量词）| 光源跑到两侧，边光全没 | "一**串**红灯笼挂在她身后" | 用**单数**；单数不够就**给画面里的尺寸**（"占画面高度的四分之一"）|
| **镜头位置**（正前齐脸高）| 光源被挪到身后 / 头顶 | "一排灯泡在她正前方、和她的脸一样高" | 挪开镜头位：**侧前 45°** 或 **正前偏下** |
| **时间里有没有太阳** | 太阳没进画，只剩余晖天 | "**黄昏**的蒲公英坡" | 写"**日落 / 日出**"+ 明写实体：`太阳还没落下去、是一个明晃晃的圆盘` |
| **因果被当成妆容** | 两坨腮红 | "脸颊被冻得有点红" | 别写"因为 X 所以 Y"，改写**皮肤本身的质地** |

⭐ **怎么用它预测新坑**：写完一句先问自己 ——
**这句话里的名词，本身带不带位置 / 高度 / 数量 / 时间 / 状态的常识？**
带，而我要的正好和相反 → **现在就换名词，别指望形容词。**

### ⭐ 镜像问题：有些词什么常识都不带 —— 空缺会被模型自己填上

上面那条讲的是**名词带的语义太强、推不动**；这一条讲的是**代词带的语义为零、填不满**。

**`两个人` / `对方` / `旁边的人` / `他` / `她` 这类指代词不携带身份信息。**
你不写清楚，模型就按先验自己补 —— **性别、年龄、关系都可能不是你想要的。**

> 用户说「一男一女」，你写成"两个人" —— 出来可能是两个男性。

⭐ **判据：把指代词删掉，还能知道这是谁吗？** 不能 → 换成具体身份
（`一名年轻女性` / `坐在右边的男性`）。

⛔ **而且不能只在开头宣告一次** —— 后面全用指代词，信息依然会漂。
详见 `01` 的「中性指代词不携带身份」一节。

### ⭐ 换不动名词时：改「光的性质」绕过

**名词推不动的第二种解法：不动名词，改光本身的性质（直射 → 散射）。**

> 用户点名要"路灯"，不能换成马灯（那是另一个画面）。
> 但路灯在头顶 → 顶光 → 脸被压平 —— 这是名词自带的高度，改不掉。
>
> ✅ **绕法**：`路灯光透过雾散开成一大片柔和的散射光` ——
> **光一旦是散射的，光源在头顶这个几何事实在脸上就不产生硬阴影了。**

⭐ 适用范围：**用户锁定了光源名词（不能换）、而它的自带语义和你要的相反时。**
直射改散射、点光源改面光源、硬光改柔光 —— 这三个是最常用的绕法。

⛔ 反面教材：为了把太阳拽到头高，在同一个方向连改四版（换支架三次），
最后发现卡的是"黄昏"两个字 —— 改成"日落"一次就出来了。

## ⛔ 改不动时：先动构图，还是换概念？

- **改光线句 1~2 次没效果** → 先**动构图**（主体的位置 / 景别 / 画幅）。
  ⭐ **构图比光更强**：同一套光，人从正脸满框挪到侧脸偏一侧，指标一次对上参考片。
- **构图也动了，同一个方向改到第 3 版还没动** → **换概念**（换场景 / 换载质 / 换画幅 / 换主体）。
  卡的是结构性的东西，继续磨措辞是纯浪费。
  ⚠️ 换概念前先过一遍上面的名词定律：有时卡的只是一个名词。
- ⛔ **"整档废掉"这种结论不能从 n=2 得出。** 同一个成像系统在一个场景里输了，
  只能说"这个组合在这个场景里不行"，不是"这一档不能用"。写死的结论比没有结论更糟。
